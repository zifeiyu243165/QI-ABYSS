# 归档说明

本目录保存**已被实现取代、但具有历史参考价值**的设计与实施方案文档。

## 为什么归档而不是删除

1. **决策可追溯**：设计期的选型理由（为什么否决 Tailwind、为什么改双资源）是理解现状的前提。
2. **避免重复踩坑**：已完成的实施方案里记着当时踩过的具体坑（9S 框饰宽度、素材比例、降级铁律的成因）。
3. **不误导新读者**：这些文档的**技术选型与部分数值已经过时**，留在 `docs/` 根目录会让接手者误以为它们仍代表现状。

## 使用规则

- **只读**：归档文件不再维护、不再更新。
- **事实以代码为准**：任何与 `src/game/` 不一致的表述，一律以代码为准。
- 需要看「现在是什么样」→ 读 [`../当前进展.md`](../当前进展.md)。
- 需要看「接下来做什么」→ 读 [`../待做项.md`](../待做项.md)。
- 需要看「过去做了什么、怎么验证的」→ 读 [`../已完成-历史交付.md`](../已完成-历史交付.md)。
