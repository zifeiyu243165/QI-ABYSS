# 《炁渊 · QI ABYSS》交付说明

新中式绮丽 · 回合制卡牌对战手游（手机竖屏 390×844）

---

## 一、已实现的系统

### 1. 双脉「炁」资源
- **阳炁**（琥珀/朱红）：主动攻击命中、击杀获得 → 消耗于物理技能
- **阴炁**（石青，原月白太淡已改）：受击、格挡成功、过牌获得 → 消耗于五行术法
- **阴阳逆转（调息）**：每回合一次，2:1 阴阳互转（春分节气效率 ×1.5）
- **炁贯周天**：单回合双脉各消耗 ≥3 → 全属性 +10% 并抽 1 张牌
- **炁量替代**：某脉不足时另一脉 2:1 替代（散修架势 1:1）

### 2. 微操三件套
- **弹反**：敌方前摇 **350ms** + 判定窗 **700ms**（总 1050ms），窗口内按下 = 完美弹反（免疫 + 追击 0.5 倍）。大雪节气自动锁定完美弹反
- **奥义卡**：两张同属性牌合并，伤害 (A+B)×1.5，不消耗额外回合
- **破绽**：回合结束按连击数/相克命中给敌人标记，下回合首张攻击牌必暴击且转真实伤害

### 3. 三大架势
| 架势 | 机制 | 终局技 |
|---|---|---|
| 体修 | 每物理牌 +1 层「势」（上限 10），层数越高倍率越高 | 10 层「破军」：攻击 × 层数真实伤害 |
| 法修 | 五行相生链（木→火→土→金→水）费用减半、伤害递增 | 相克可打断并附加虚弱 |
| 散修 | 阴阳差值越大暴击率/暴伤越高 | 差值 ≥6「剑走偏锋」：伤害 +100%，回合结束自损 30% |

### 4. 装备与附魔
- 3 兵刃（唐刀/锏/苗刀）+ 3 法器（离火镜/坎水佩/五雷令）
- 9 行组合映射：唐刀+离火镜=赤焰斩、+坎水佩=霜寒斩、+五雷令=奔雷斩……
- 流派：双兵刃=纯阳武圣（50 层「开天」攻击 ×50）、双法器=五运阴阳、一兵一法=阴阳合契

### 5. 心猿（有阴有阳）
| 阵营 | 本质 | 成员 | 数值 |
|---|---|---|---|
| **阴执** | 都市负面戾气化形 | 焦躁鬼 / 加班怨灵 / 贪嗔蠹 | 110 / 150 / 130 气血 |
| **阳华** | 被正气与节令淬炼的精怪（**绚烂华贵，不阴森**） | 金吾卫 / 惊蛰·春雷兽 / 霜降·冰魇 | 175 / 380 / 430 气血 |

- 每只心猿有独立**招式牌组**（品阶：常/技/凶/杀）+ **「势」资源**（出招有成本，不足则回气）
- 阴执是「心理问题的怪物」，阳华是「有立场、有气质的对手」——胜利是切磋，不是除魔

### 6. 五层变量联动
月令（12 地支，含得令/失令）→ 炁候（24 节气留位，实装 8）→ 十神（10 条留位，实装 6）→ 架势 → 装备

### 7. 角色与内容
- 3 名角色：陆青崖（庚金·七杀+正财）、苏绛雪（癸水·正印+偏财）、谢无咎（丙火·伤官+食神）
- 6 个心猿（阴执 3 / 阳华 3，含 2 BOSS）、4 场线性战役
- 26 张卡（物理 8 / 术法 10 / 功能 4 / 节气限定 4）

## 二、关键架构决策

### 结算管线：用类型系统强制「性命双修」
五层变量统一抽象为 `DamageModifier{ op: 'addBase' | 'addFlat' | 'mul' }`。

- `addBase`（直接加基础攻击力）**只有装备可用**，其他来源运行时抛错
- 加法只发生在两处：`effectiveAtk = 角色atk + 兵刃`、`base = ceil(effectiveAtk × 卡倍率) + addFlat`
- 其余一律乘法 → **五层计算顺序与结果无关**，消除整类顺序依赖 bug
- 刮痧下限：有效攻击力低于 `防御 × 1.5` 时伤害压到 10% —— 「数值是地基，机制是高楼」的代码表达

七阶段：基数 → 卡倍 → 收集 → 连乘 → 暴击 → 减伤（含刮痧下限）→ 护盾，输出全量 `DamageBreakdown` 可断言。

### 节气 Hook 化
`src/game/engine/hooks.ts` 是**全引擎唯一读取 `solarTermId` 的地方**。所有节气效果以钩子数据表达，钩子只返回 `Effect[]`、从不直接改 state。新增第 9 个节气只需在 `data/world.ts` 加一条数据，引擎零改动。

### 确定性
引擎内禁止 `Math.random` / `Date.now`，随机一律走 `state.rngState`（mulberry32）。弹反时间由 UI 传入 `elapsedMs`。因此相同种子必然产生相同战局，单测可断言。

### 视觉
- 角色/心猿立绘：AI 生成图（真透明 PNG）优先，加载失败回退 SVG path 程序化生成
- 五行纹样 / 八卦底盘 / 状态图标：SVG 程序化生成（`svg/Glyphs.tsx`）
- 打击特效：Canvas 粒子（墨染 + 金箔碎片）、DOM 伤害数字爆裂、卡帧 100~300ms
- 节气物候：Canvas 飘落（花瓣/麦穗/雪花/雨/落叶/火星/霜）
- 三级特效降级：华丽 / 标准 / 简洁

### 配色铁律
`src/styles/tokens.css` 是**全项目唯一出现 hex 的文件**，其余一律 `var(--color-*)`。
基调为**汉唐明媚**：宣纸米白 / 竹简暖黄 / 描金 / 青绿山水（石绿石青）/ 玉石金丝楠，
严格五正色（朱红/石青/松花绿/明黄/月白/琥珀黄 + 缟素/鸦青），无荧光紫、荧光粉、赛博霓虹蓝，无纯黑背景。

## 五、技术栈

Vite 8 + React 19 + TypeScript 6 + oxlint + vitest。无第三方 UI 库、无状态管理库。

> 否决 MUI 的理由：Material Design 的语言（卡片阴影、Roboto、水波纹）与「新中式绮丽」正面冲突。
> 否决 Framer Motion 的理由：奥义卡需要双指/多指手势，其 drag 不支持多指。

### 美术资源

`public/art/` 下位图（角色 3 / 心猿 6 / 背景 1），总计约 1.5MB。

- 角色立绘：重新生成时在 prompt 中写死「纯白背景、无建筑、无天空、无地面阴影、无光效」，再走自研 flood-fill 抠图管线转真 alpha。
- 敌人立绘：对原图做抠图处理。
- 体积：21MB → 1.5MB（-93%），透明通道完好。
- 兜底：任一张图加载失败（`onError`）会自动回退到程序化 SVG 立绘，游戏不会白屏。
- **全部资源的生成提示词见 [`public/art/素材提示词.md`](../public/art/素材提示词.md)**，按同名文件覆盖即可生效。
