# 战斗界面接入验收截图

本目录保存「29 张界面零件素材接入战斗界面」这一轮的验收证据。
截图由 `scripts/界面核验.mjs` 生成（真实浏览器三相：素材齐全 / 素材缺失降级 / 恢复），
跑法与说明见该脚本头部注释。

## 降级铁律（为什么右图长这样是对的）

项目约定：**素材缺失时不白屏、不报错、不塌布局，自动回落为纯 CSS 外观**。

实现方式是**兄弟三层**——① 基底 CSS 层（渐变 / 描金边 / 圆角，**常驻 DOM**）；
② 素材叠加层（`ArtLayer`，`background-color: transparent`）；③ 内容层（文字，z 最高）。
图缺失时叠加层渲染为空，基底原样可见。

因此右图**不是**「坏掉的界面」，而是素材全部缺席时本该有的样子：布局、尺寸、文字位置与左图**逐像素一致**，
只是少了描金纹样。核验脚本对两相都断言了 `pageError === 0` 且 `consoleError === 0`。

> 注意：CSS 的 `background-image` / `border-image` 加载失败**不会**抛错（只有 `<img>` 会）。
> 所以本项目**不用** `onError` 探测素材，也不做「图存在才渲染」——那会导致白屏。
