## 0. 原始需求复述

开发者提供了一份极其完整的创意企划书：以道教"炁/周天"哲学、二十四节气、命理学十神为骨架，融合现代都市怪谈（心猿）的新中式回合制卡牌手游。核心体验口号为**"回合制里的动作游戏"**——每回合充满弹反微操、连携搓招、资源博弈与视听轰炸。

企划完整度为满分，但存在**严重范围爆炸**：24 节气 × 10 十神 × 3 架势 × 装备组合 × N 角色全做在工程上不可行。

**本 PRD 的核心价值 = 范围收敛**。在不破坏"战斗爽"核心体验的前提下，砍出一个可在单次交付内跑通的**可玩闭环**。

**收敛总原则**：宁可"变量少但每层都真实生效"，不要"层多但每层都是空白石板"。五层联动（月令 → 炁候 → 十神 → 架势 → 装备）**全部保留并在 MVP 中真实生效**，只是每层的候选元素数量被压缩。这样策略深度的*结构*被完整验证，后续扩展只是填表。

## 1. 产品定义

### 1.1 Product Goals

**G1 · 让每一回合都有决策重量（Lifelong Loop）**
玩家在 30 秒的单场战斗中，每一次出牌、每一次调息、每一次格挡都能看到即时且夸张的正/负反馈。衡量标准：单场战斗平均操作次数 ≥ 12 次（出牌 + 调息 + 格挡 + 架势切换之和），"无事可做直接结束回合"的比例 < 15%。

**G2 · 把"挨打"变成"攒资源"（Emotion Conversion）**
通过双脉炁机制，让被压制回合产生战略收益而非挫败感。衡量标准：测试局中出现 ≥1 次"血量低于 30% 后完成翻盘"的比例 ≥ 40%。

**G3 · 用零美术资源兑现"新中式绮丽"（Aesthetic Floor）**
在完全无图片的前提下，通过五正色体系 + 程序化 SVG 角色 + Canvas 墨染金箔粒子 + 卡帧，达到"截图可辨识为中式而非generic卡牌游戏"的视觉下限。衡量标准：任意战斗截图去除UI文字后，主色仍严格落在五正色 + 缟素/鸦青色盘内，零荧光色。

### 1.2 User Stories（执令者视角）

- **US-1**｜作为一位**首次打开的玩家**，我希望在 15 秒内进入第一场战斗，这样我不需要阅读长篇教程就能知道这游戏怎么玩。（对应：序章即用战，战斗中渐进式提示）
- **US-2**｜作为一位**追求操作的玩家**，我希望在敌人攻击落下的瞬间按下格挡完成弹反，这样我能获得"这操作我练出来的"的成就感。（对应：0.6s 微操窗口 + 完美弹反金色水墨字 + 镜面碎裂反馈）
- **US-3**｜作为一位**喜欢算牌的玩家**，我希望通过攒满 10 层"势"打出无视防御的真实伤害一刀清屏，这样我的资源规划能得到爆发回报。（对应：体修架势 · 破军）
- **US-4**｜作为一位**处在劣势的玩家**，我希望上一回合挨的打能转化成阴炁，让我这回合能翻回来，这样我不会因为一波失误就想退出。（对应：阴炁获取 + 周天循环 + 2:1 替代规则）
- **US-5**｜作为一位**喜欢构筑的玩家**，我希望给角色换上不同兵刃/法器组合后普攻会改名变色（赤焰斩/霜寒斩/奔雷斩），这样我的搭配能肉眼可见地生效。（对应：双槽装备 + 附魔招式变化）
- **US-6**｜作为一位**重开关卡的玩家**，我希望每次开局抽到不同节气会逼我换一套打法，这样重复刷不会无聊。（对应：8 节气随机炁候 + 节气限定卡入池）
- **US-7**｜作为一位**在意氛围的玩家**，我希望战斗结算后能看到"本局得意的一击"复盘数据而不是一堆评分数字，这样我有截图分享的欲望。（对应：命理复盘 · 最高连携/最高单次伤害）

## 2. 范围收敛详细论证

### 2.1 战斗形态：**推荐 1 名主控角色 vs 敌方 1–3 只心猿**（非对称 1vN）

**推荐方案：放弃 3v3，采用 1 v N。**

理由（按权重排序）：

1. **竖屏物理放不下。** 390px 宽下真实可用于战场的高度约 620px。若 3v3，需同时渲染 6 个单位的状态位（HP + 双炁 + 破绽 + 异常状态角标），单单位可用面积 < 100×120px。我们的视觉方案是程序化 SVG 剪影，缩到这个尺寸后"立绘"退化为色块，G3 目标直接失败。1vN 下敌方虽仍多，但只有我方需要完整状态渲染。
2. **我方多人会引发连锁的系统性膨胀。** 一旦我方 3 人上场，就必须同时实现：友方站位、嘲讽/保护指向、"比肩"（每有 1 名友方存活攻击+5%）等群体类十神、友方复活/换阵、以及对面 AI 的**目标选择 AI**。目标选择 AI 是回合制里最不起眼但最容易做崩的模块。砍掉我方多人，这五个模块全部消失。
3. **1vN 反向验证了大量企划元素的可行性。** 注意到一个关键事实：企划书中**"正官"（封印敌方手牌）与"比肩"（友方数量增益）在 1vN 下直接失效**——敌方没有手牌系统，我方没有队友。这不是缺陷，而是收敛的信号：它证明了 1vN 与删减后的十神池是**自洽的一套设计**，而非东砍一刀西砍一刀。
4. **核心爽点不受损。** "回合制里的动作游戏"依赖的是**弹反微操 + 卡帧 + 连携 QTE**，全部是 1v1 级别的交互，与队友无关。而 N 个敌人反而 *强化了* "破军一刀清屏"和"AOE 五行连环炸裂"的清场快感。
5. **无美术资源下的人效。** 需程序化生成的敌人只有"敌方模板复用 + 换色换符"，而我方主角可以有完整的大幅立绘区。

**具体规格：**
- 敌方最多 **3 个站位**（左/中/右），按数量自动排布；BOSS 占中央大格，尺寸为主力型 1.8 倍。
- 我方主控区固定在屏幕下三分之一（详见 §5.3），大幅竖幅 SVG 立绘，**这是全局唯一的"大件美术"，必须重点投入**。

### 2.2 节气（炁候）：**MVP 做 8 个，数据结构预留 24 槽**

选择标准是**效果类型正交**，而非"最有名"。8 个必须覆盖"资源流转 / 强制进攻 / 防御强化 / 数值修正 / 控制 / Debuff附加 / 操作辅助"七类机制，且四季均分（每季 2 个），这样随机抽到任何一个都会实质改变打法。

| # | 季 | 节气 | 战场效果（MVP 实现版） | 覆盖的机制类型 |
|---|-----|------|----------------------|--------------|
| 1 | 春 | **立春** | 开局抽 1 张额外手牌；首回合获得 2 层"势" | 起手增益 / 体修友好 |
| 2 | 春 | **惊蛰** | 首张攻击牌伤害 +50%，但该牌炁消耗翻倍 | **资源博弈**（重拳 vs 留存） |
| 3 | 夏 | **芒种** | 每回合必须打出 ≥2 张攻击牌，否则自扣 10% 最大生命 | **强制进攻**（行为约束） |
| 4 | 夏 | **大暑** | 所有伤害 +20%，治疗与护盾效果 -50% | **数值修正**（拼刺刀白刃战） |
| 5 | 秋 | **白露** | 术法牌额外消耗 20% 阴炁，但命中必附加"霜寒"（减速+破甲） | **Debuff 附加**（高投入高回报） |
| 6 | 秋 | **霜降** | 暴击附带"冻结"（跳过下回合），但暴击伤害固定为 150% | **控制**（伤害换绝对控制） |
| 7 | 冬 | **大雪** | 所有"格挡"自动升级为"弹反"（无需卡时机） | **防御强化 / 操作辅助**（新手友好） |
| 8 | 冬 | **冬至** | 每回合结束，阴阳两脉自动向较低一方补充，补充量 ×2 | **资源流转**（被动维稳） |

> **砍掉的 16 个节气：`implemented: false`，保留完整数据定义**（id / name / season / desc / hooks 占位），抽取逻辑只从 `implemented === true` 的池中取样。**这是给未来 DLC 的显式接口**，不得省略字段。

**数据结构要求（对架构师的硬约束）**：节气效果必须是**声明式 hook 配置**，禁止 hardcode if-else。每个节气提供一个 `hooks` 对象，包含可选钩子：`onBattleStart` / `onTurnStart` / `onTurnEnd` / `onCardPlayed` / `onDamageDealt` / `modifyCardCost` / `modifyDamage`。战斗引擎按钩子名查表调用。这样新增 16 个节气 = 新增 16 条数据，零改引擎代码。

### 2.3 十神：**MVP 做 6 个，每角色 1 主星 + 1 辅星**

入选的 6 个必须覆盖互不重叠的战术轴，且**每一个都能被玩家明确感知到触发瞬间**（有飘字/有特效/有音效）：

| 十神 | 分类 | MVP 效果（原文照搬，已验证可实现） | 战术轴 |
|------|------|--------------------------------|--------|
| **正印** | 印星 | 每回合首次受致命伤害时锁血 1 点（强制存活），触发后本回合技能消耗翻倍 | **保命 / 翻盘** |
| **七杀** | 官杀 | 击杀任意单位后，本回合剩余所有牌费用减半；隐藏被动：自身血量 <10% 时本回合伤害 +30%（杀身成仁） | **滚雪球斩杀**（核心爽点，必留） |
| **伤官** | 食伤 | 暴击伤害由 150% 提升至 200%，但暴击率 -20% | **暴击天花板**（高风险产出） |
| **正财** | 财星 | 每回合造成伤害后额外获得 1 阳炁 + 1 阴炁 | **资源续航** |
| **偏财** | 财星 | 每次抽牌 20% 概率额外抽 1 张（触发后本回合不再触发） | **过牌 / 运气惊喜** |
| **食神** | 食伤 | 连击段数 +2，但每段伤害固定为 80% | **多段触发**（配合的技能被旁路） |

**砍掉的 4 个及理由**：
- **正官**（封印敌方手牌）→ 敌方无手牌系统，1vN 下直接失效。**这是形态选择的连带收益，不是损失。**
- **比肩**（友方存活数增益）→ 我方仅 1 人，永远 +5%，无意义。
- **偏印**（免疫首次受控）→ MVP 敌方控制手段少，触发率低且玩家感知弱。
- **劫财**（复制效果）→ 需要一个"效果执行栈"抽象才能安全复制任意卡牌效果，是**全部 10 神里工程成本最高、收益最难感知**的一个，明确推迟到 P1。

**辅星实现方式**：辅星效果直接沿主星实现，只是**数值/触发时机参数不同**（如食神段数+2 → 作为辅星时为 +1）。不得为"主星"和"辅星"写两套代码路径。

### 2.4 角色：**3 个原创角色，覆盖三大架势 + 三个不同日主五行**

| # | 角色 | 日主五行 | 默认架势 | 十神（主/辅） | 推荐装备 | 流派定位 |
|---|------|---------|---------|-------------|---------|---------|
| 1 | **陆青崖** | 庚金 | 体修·连击蓄势 | 七杀 / 正财 | 唐刀 + 离火镜 | 阴阳合契（物理+火附魔） |
| 2 | **苏绛雪** | 癸水 | 法修·五行轮转 | 正印 / 偏财 | 三清铃 + 坎水佩 | 五运阴阳（双法器术法） |
| 3 | **谢无咎** | 丙火 | 散修·刀尖舔血 | 伤官 / 食神 | 锏 + 金钱镖 | 纯阳武圣（双兵刃物理） |

**背景故事（一句话）：**
- **陆青崖**：白天是跑单最快的外卖骑手，夜里是把唐刀藏进外卖箱的执令者——他说跑单和斩妖一样，都讲究一个"快"字。
- **苏绛雪**：二十四小时便利店的夜班店员，能从扫码枪的滴滴声里听出哪只心猿正在说谎。
- **谢无咎**：直播间榜一大哥，永不下播的那种——他从不回避死亡，只是把赔率都押在了自己这一边。

**得令 / 失令判定（MVP 简化版，三态）**

| 状态 | 判定条件 | 效果 |
|------|---------|------|
| **得令** | 角色本命五行 == 月令五行 | 每回合自动 +1 阳炁 +1 阴炁，全技能倍率 +10% |
| **失令** | 角色本命五行**被**月令五行所克 | 每回合首张牌消耗 +1 炁，暴击率 -10% |
| **中性** | 其余（含相生、我克月令两种情况） | 无修正 |

MVP 静态月令「申月·金旺」下的实际推演：

| 角色 | 本命 | 与月令关系 | MVP 内状态 |
|------|------|-----------|-----------|
| 陆青崖 | 庚金 | 金 == 金 | **得令** ✅ 每回合自动回炁 + 倍率+10% |
| 苏绛雪 | 癸水 | 金生水（月令生我） | 中性 |
| 谢无咎 | 丙火 | 火克金（我克月令） | 中性 |

> ⚠️ **对工程的重要提示**：MVP 中没有木行角色，因此「**失令**分支在本版不会被自然触发**。但该逻辑**仍必须实现并保证正确**（配置表已就绪，未来接入第 4 个木行角色或动态月令后立即生效）。请勿因为"跑不到"就跳过失令分支——请自行构造单元测试覆盖它。
>
> ⚠️ **命理学精确性**：本方案刻意采用简化规则（被克=失令、我克=中性），**不追求传统术数的严谨性**。前提是规则内部一致且 UI 明确告知玩家当前状态。如有考据要求，见 Open Questions · Q3。

### 2.5 卡牌：**MVP 26 张**

| 类别 | 数量 | 说明 |
|------|------|------|
| 物理牌 | **8** | 消耗阳炁。含 1 张 MOOK 普攻、3 张单体、2 张多段、1 张 AOE、1 张终结技《开天》前置牌 |
| 五行术法牌 | **10** | 消耗阴炁。金木水火土**各 2 张**（1 单体 + 1 群体/特殊），保证五行轮转相生成环（木→火→土→金→水）可行 |
| 防御/功能牌 | **4** | 护盾、驱散、治疗、抽牌各 1。支撑"挨打不全是坏事"的资源循环 |
| 节气限定牌 | **4** | 《立春·破土》（土/抽牌+势）、《大暑·流火》（火/AOE）、《霜降·凝华》（水/单体冻结）、《大雪·封山》（水/群体减速）。**仅当本局炁候为该节气时加入卡池** |

**奥义卡（连携 QTE）不占卡池**。它由两张同属性手牌在局内双指合并动态生成，是**运行时产物而非卡表条目**。这一条必须提前说清，否则会出现"26 张卡表为何能打出第 27 种牌"的实现歧义。

### 2.6 装备：**3 兵刃 + 3 法器 = 6 件**

选择标准是**必须能同时演示三大流派 + 企划原本写到的三个招牌组合**：

**兵刃（3）**
| 名称 | 基础攻击 | 连击段数 | 物理特效 |
|------|---------|---------|---------|
| **唐刀** | +18 | 2 | 流血 |
| **锏** | +26 | 1 | 破甲 |
| **金钱镖** | +12 | 3 | 击退 |

**法器（3）**
| 名称 | 炁上限 | 五行 | 术法特效 |

## 3. 核心系统规格（保留并实现的变量层）

### 3.1 五层变量联动（MVP 全部真实生效）

| 层级 | 变量 | MVP 变化频率 | MVP 状态 |
|------|------|-------------|---------|
| 第一层 | 月令（地支） | 静态常量 | 固定「申月·金旺」，表内预留 12 条 |
| 第二层 | 炁候（节气） | **每局随机 1 个** | 8 个已实现 / 24 槽位 |
| 第三层 | 十神命格 | 角色固定，1主+1辅 | 6 个 |
| 第四层 | 战斗架势 | **局内可切换**（消耗本回合行动机会） | 3 个全做 |
| 第五层 | 装备组合 | 战前预设，双槽 | 6 件 |

**"性命双修"铁律必须在代码层落实**：伤害公式严格为 `(基础攻击 × 架势倍率 × 节气修正 × 月令修正) - 敌方防御`，**任何 DOT / 冰冻 / 连击 / 异常的触发都不允许绕过这个乘法基数**。建议架构师在代码里加一条断言/单测：当攻击 ≤ 防御时，所有附加特效伤害应 ≤ 基础伤害的某阈值。

### 3.2 双脉炁（局内核心资源）

| 资源 | 颜色 | 获取 | 消耗 |
|------|------|------|------|
| **阳炁**（任脉） | 朱红 `#C23B22` | 主动攻击命中、击杀敌方 | 物理技能、爆发终结技 |
| **阴炁**（督脉） | 月白 `#D6ECFF` | 受击、格挡成功、过牌/弃牌 | 五行术法、控制技、回复/驱散 |

- **炁量替代规则（容错）**：某脉不足时可用另一脉 2:1 替代。散修架势提升至 1:1。
- **周天循环**：每回合一次免费"调息"，按 2:1 转换；若单回合内两脉消耗均 ≥3 点 → 触发**"炁贯周天"**：全属性 +10%，立即抽 1 张牌。

### 3.3 三大架势

| 架势 | MVP 核心机制 | 终局爽点 |
|------|-------------|---------|
| **体修·连击蓄势** | 每张物理牌攒 1 层"势"（上限 10），层数越高下张物理牌倍率越高；10 层解锁"破军"：无视防御的真实伤害 | **卡帧 0.3 秒 + 一刀清屏**，纯白字数字炸裂 |
| **法修·五行轮转** | 五行相生顺序（木→火→土→金→水）连续出牌，每张费用减半且伤害递增 10%；相克可打断蓄力 | 满屏五行符文连环炸裂 |
| **散修·刀尖舔血** | 阴阳差值越大，暴击率与暴击伤害越高；差值达上限触发"剑走偏锋"：本回合伤害 +100%，回合结束自损 30% 当前血量 | 极致心跳的数字豪赌 |

### 3.4 微操三件套（"回合制动起来"的落点，**优先级最高**）

1. **格挡与弹反**：敌方回合显示大号格挡按钮。敌方攻击前摇期间（**0.6 秒微操窗口**）按下 → **弹反**：全额免疫本次伤害 + 追加 1 次无消耗"追击"（伤害 = 攻击 × 0.5）+ 屏幕金色"反弹"水墨字 + 镜面碎裂音效。
   - **需要无音效时的降级方案**：见 §6 · D3。
2. **连携 QTE**：手牌中两张同属性牌双指滑动合并 → **奥义卡**，伤害 = 原两卡之和 × 1.5，不消耗额外回合，全屏特效。
   - **桌面端降级**：双指滑动在无触屏环境不可用 → 桌面端提供"按住拖卡牌 A 覆盖到卡牌 B"的鼠标等价操作。
3. **破绽系统**：回合结束按连击数/克制命中数给敌方标记"破绽"（金色光圈，持续到下回合结束）；下回合对该敌方**首张攻击牌必定暴击且转为真实伤害**（无视防御）。

## 6. 视觉技术方案：**零素材下的"新中式绮丽"降级路径**

> **前提约束（务必向所有下游角色传达）：本项目没有任何 png/jpg/svg 文件，不得假设存在任何图片目录。**

| 视觉元素 | 无素材方案 | 备注 |
|---------|-----------|------|
| **角色立绘** | **SVG 程序化"剪影 + 五正色渐变"**：人形轮廓 path + 线性渐变填充 + 大氅飘动的 CSS transform 动画 + 1 个高光描边。五官不画（或仅极简墨线），走"写意剪影"路线，**规避二次元画不好导致的廉价感** | 这是刻意的美学选择，不是偷工减料 |
| **水墨味** | SVG `<feTurbulence>` + `<feDisplacementMap>` 滤镜对剪影边缘做扰动，产出毛笔飞白边缘 | 低成本，效果好 |
| **敌人** | 几何符形：SVG 多边形 + 本命五行着色 + 旋转抖动动画（如"刷卡魇"= 破碎的方形卡片环） | 每个敌人一条 svg path 即可 |
| **打击特效** | **Canvas 粒子层**：受击点生成 20~40 个墨点（鸦青→缟素渐变，重力下落）+ 15 个金箔碎片（琥珀黄矩形，带旋转反光） | 使用 `requestAnimationFrame`，粒子池复用，池上限 200 |
| **卡帧 Hitstop** | 命中瞬间 `ctx.pause` 0.1~0.3s（随伤害倍率递增）+ 屏幕 Y 轴 3px 抖动 + 白闪 | 必须在 P0，"打击感"的最低保障 |
| **伤害数字** | DOM 元素绝对定位 + CSS `scale(0.2) → scale(1.3) → scale(1)` 爆裂关键帧，而非普通飘字。物理=月白数字，五行=对应色数字，暴击=字号×1.6 + 水墨飞溅轨迹 | 见 D2 降级 |
| **书法字体** | 系统字体栈：`"STKaiti","KaiTi","Kaiti SC","楷体",serif`，禁止引入 webfont（无网络依赖） | Linux/部分安卓 fallback 到 serif，可接受 |
| **节气物候** | Canvas 背景粒子层（桃花瓣/麦穗/雪花） | P1 |
| **音效** | **Web Audio API 程序化合成**：金石声 = 短促方波 + 高通滤波；雷暴 = 白噪声 + 低通扫频；镜面碎裂 = 多个高频正弦叠加快速衰减 | 零素材前提下唯一可行路径 |

### 已识别的视觉降级风险点（Open Questions 已登记）

- **D1 · 程序化角色可能不够"绮丽"**。缓解措施：把视觉预算压在**主控的大幅剪影**上（唯一"明星位"），敌人走抽象几何，反而形成"主角精致 / 妖邪失形"的合理层级——这与"心猿本就是杂念化身"的设定是自洽的。
- **D2 · Canvas 粒子在低端机上掉帧**。降级开关：设置项「特效强度：华丽/标准/简洁」，简洁档关闭粒子只保留卡帧与数字爆裂。
- **D3 · 无 mp3 音效**。全部走 Web Audio 合成。若时间不足，**保留卡帧 + 屏幕抖动 + 数字爆裂，音效降为最低优先级**（打击感三要素里有两项已达标）。
