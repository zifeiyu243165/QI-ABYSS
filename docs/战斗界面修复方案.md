# 战斗界面 8 项修复 · 架构方案

> 本文是「战斗界面 8 项问题修复」的工程依据，由架构师高见远产出、主理人齐活林汇编。
> 用户决策（2026-09-17）：① 只修战斗界面，新界面与主界面美化另立待做项文档；

## 三、择道面板（① ）

- 全屏 flex 列，基底用 `AmbientBackground`（从 `Screens.tsx` 导出复用）+ `GoldPanel`；**禁 `<dialog>` / 第三方**。
- 三张卡 = 三个 `CHARACTERS`（与 `STANCES` 1:1）。每卡显示：`CharacterFigure` + 姓名 + 日主印 + 十神 + 架势名 + 玩法说明（`STANCES[].desc`）+ 装备摘要（读 `save.equipment[c.id]`）。
- 选中态 = 描金粗边 + 上浮；底部 `JadeButton primary` = `t('ui.select.confirm')`。

### 数据流
1. `Screens.tsx` 的「入局」：`onStart` 由 `enterBattle` 改为 `() => setScreen('select')`。
2. `App.tsx` `type Screen` 增 `'select'`；渲染分支调 `StanceSelectPanel`，`onConfirm(cid)` → `setSave({selectedCharacterId:cid})` + `startBattle(cid 的战役, cid)`。
3. `startBattle` 签名改 `(cid: string, characterId: string)`，内部用**传入的** `characterId` 与 `save.equipment[characterId]`（**不再读闭包里的 `save.selectedCharacterId`**，避免陈旧值）。

```
玩家点「入局」→ setScreen('select') → 面板（预选高亮，单击即生效）
  → 点「入局开战」→ setSave(selectedCharacterId) → startBattle(cid, charId)
  → setShowIntro(true) + setScreen('battle')
```

### 对局内架势切换（保留两段式）
单击架势 → 立即预选（明黄框移动）→ 点「确认」→ `dispatch SWITCH_STANCE`。
**语义说明**：择道面板选的是**角色**，其对局内默认架势 = `char.stance`；对局内切换**只换架势机制**（`state.stance`），角色的 `wuxing`/`rizhu`/`shishen` 不变（解绑 = 引擎大改，属红线）。

## 七、特效方案（⑤⑧）

### 技术选型
全 Canvas/CSS，**零新素材**。`FxLayer` 在 UI 层**允许** `Math.random`；引擎 `game/engine/**` **严禁**（凡影响战斗结果的随机走 `state.rngState`，特效外观随机留 UI 层）。颜色统一经 `readToken()`，**不写 hex**。

```ts
// src/components/fx/readToken.ts
const cache = new Map<string, string>();
export function readToken(name: string): string {
  const key = name.startsWith('--') ? name : `--color-${name}`;
  const hit = cache.get(key);
  if (hit !== undefined) return hit;
  const v = getComputedStyle(document.documentElement).getPropertyValue(key).trim();
  cache.set(key, v);
  return v || 'transparent';
}
```

### 粒子参数表
| 粒子 | 触发 | 颜色 | 初速/重力 | 寿命 | 混合 |
|---|---|---|---|---|---|
| 墨点（现有） | physical | `readToken('--color-yaqing')` | 1.2–4.6 / 0.16 | 26–48 | source-over |
| 金箔（现有） | crit | `readToken('--color-minghuang')` | 同上 | 同上 | source-over |
| 五行火花（新） | spell 按 `WuXing` | `readToken('--color-wx-'+wx)` | 3–6 / 0.05 | 14–26 | **lighter** |
| 碎石（新） | physical / AoE | `readToken('--color-card-text-sub')` | 2–5 / 0.3 | 20–40 | source-over |
| 冲击波环（新） | crit / 奥义 | `--color-miaojin` 或 wx | 半径 8→70 缓出 | 22 帧 | lighter |
| 拖尾（新） | 高伤 | 继承主色 | 记录前 3 位置 | — | lighter |

- **按 kind 分形分色**：`DamageNumber.kind`（`'physical'|WuXing|'heal'|'true'`）已在手 → `burst(x, y, intensity, kind?)` 增第 4 参，`useBattleFx.ts` 传 `n.kind`。
- **卡帧澄清**：引擎**已**按 `totalMul` 分级写 `pendingHitstopMs`（`HITSTOP_MIN/Max`）。`useBattleFx.ts` 的 **850ms 是特效消费窗口，不是卡帧时长** —— **勿改**它去"修卡帧"。
