## 1. 三十秒看懂这个游戏

你是一名**执令者**，在都市霓虹的阴影里斩除由人心杂念化成的**心猿**。

战斗是**回合制**，但不是站桩对拼。每一回合你要同时管三件事：

| 你要管的 | 具体是什么 | 失败代价 |
|---|---|---|
| **炁**（资源） | 阳炁打物理、阴炁放术法，两脉可 2:1 互转 | 没炁 = 出不了牌 |
| **时机**（操作） | 敌人抬手的 0.7 秒里按下格挡 | 按错挨满伤害 |
| **牌**（构筑） | 手牌合并成奥义、按五行顺序连携、攒势打真实伤害 | 伤害平庸，被拖死 |

**三个"爽点"关键词**：

- **弹反** —— 在金色窗口按下去：**免伤 + 免费追击 + 全屏金色「反弹」水墨字**。
- **破军** —— 体修攒满 10 层「势」，一刀**无视防御的真实伤害**，300ms 卡帧 + 屏幕抖动。
- **奥义** —— 两张同属性牌合并，伤害是**两张牌之和 × 1.5**，白嫖一个回合。

**一局多久？** 4 场线性战役，单场 8–15 回合，全程约 15–25 分钟。

## 2. 一次对局的完整流程

### 2.1 从主界面到战斗

```
主界面「入局」
   ↓
开场仪式（约 3.6 秒，点击可跳过）
   ① 播报月令   → ② 毛笔字浮现本局炁候   → ③ 砸下日主与十神印章
   ↓
战斗（第 1–N 回合循环）
   ↓
胜负判定 → 结算页「命理复盘」→ 下一战 / 再来一次 / 回主界面
```

### 2.2 每回合的六步循环

```
【我方回合】
  ① 回合开始
     └ 得令回炁（仅得令角色）→ 灼烧结算 → 抽 3 张牌 → 节气 onTurnStart
  ② 自由行动（顺序随意，可反复）
     ├ 出牌（消耗炁）
     ├ 合并奥义（两张同属性牌）
     ├ 调息（每回合 1 次，2:1 转炁）
     └ 切换架势（每回合 1 次，消耗本回合行动）
  ③ 点「结束回合」
     └ 节气 onTurnEnd（如芒种：未打够 2 张攻击牌则自扣 10% 血）
     └ 破绽判定（连击 ≥3 或相克命中 ≥1 → 给某个敌人挂「破绽」）
     └ 剑走偏锋反噬（散修专属，若阴阳差 ≥6，自损当前血量 30%）
   ↓
【敌方回合】
  ④ 敌方前摇 350ms（红区）——此时**可以按格挡**，但按了算「过早」
  ⑤ 判定窗 700ms（金区）——此时按下 = **完美弹反**
  ⑥ 敌方结算（攻击 / 蓄力 / 防御 / 群攻）
   ↓
回到 ①，turn + 1
```

> ⚠️ **关键时序**：从敌人抬手到攻击落地共 **1050ms**（350 + 700）。
> UI 上是一条**从左往右跑的游标**，前 350ms 走红区，后 700ms 走金区。
> 游标跑完还没按，就按"未格挡"结算——挨满伤害。

### 2.3 胜负条件

| 结果 | 条件 |
|---|---|
| **胜（心猿已除）** | 场上所有敌人 HP = 0 |
| **负（道消）** | 玩家 HP = 0（正印锁血可救一次，见 §13） |

## 3. 双脉炁：本作的核心资源

### 3.1 两条脉

| | **阳炁**（任脉） | **阴炁**（督脉） |
|---|---|---|
| **颜色** | 琥珀黄 `#CA6924` | 月白 `#D6ECFF` |
| **用途** | 物理牌（斩风、劈山、回旋斩…） | 五行术法牌（离火咒、寒冰咒…） |
| **来源** | ① 攻击命中　② **击杀敌人 +2**　③ 回气丹 +2　④ 聚炁 +1　⑤ 得令 +1/回合　⑥ 正财 +1 | ① **受击 +1**　② 完美弹反 +1　③ 潮生诀 +2　④ 回气丹 +2　⑤ 得令 +1/回合　⑥ 正财 +1 |
| **上限** | 10 + 法器加成 | 10 + 法器加成 |

> 起始资源：**阳 3 / 阴 3**。
> 每件法器 **+4 上限**；双法器 = 上限 18。所以"能不能带够术法"本身就是构筑决策。

### 3.2 炁量替代（容错机制）

某一脉不够时，可以拿**另一脉按比例顶替**：

| 架势 | 替代比例 | 含义 |
|---|---|---|
| 体修 / 法修 | **2 : 1** | 缺 2 点阳炁，用 1 点阴炁换 |
| **散修** | **1 : 1** | 缺 1 点阳炁，用 1 点阴炁换（散修是唯一 1:1 的架势） |

**举例**：你要打「崩拳」（阳 2），手里只有 0 阳、5 阴。
- 体修：需要 2×2 = 4 阴 → 够，打出后剩 1 阴。
- 散修：需要 2×1 = 2 阴 → 打出后剩 3 阴。

> 这是设计上"**不让你卡手**"的兜底。代价是替代很亏，逼你规划炁脉。

### 3.3 调息（周天循环）

每回合**限一次**，手动把一脉换成另一脉：

```
调息：消耗 2 点 → 获得 1 点（默认 2:1）
春分节气：效率 ×1.5，即 2 点 → 1 点（取整后实际更优）
```

UI 上的「调息」按钮会**自动判断方向**：哪一脉多，就转成少的那一脉。

> 调息是**免费行动**，不消耗出牌次数，但一回合只有一次。它是你把"打错的节奏"救回来的唯一手段。

### 3.4 炁贯周天（隐藏爆发）

**同一回合内**，阳炁与阴炁**各消耗 ≥ 3 点** → 立刻触发：

| 效果 | 数值 |
|---|---|
| 全属性加成 | **伤害 ×1.1**（乘法） |
| 额外收益 | **立刻抽 1 张牌** |

> 这是**鼓励混合出牌**的机制。纯物理流永远触发不了它，纯术法流也触发不了。
> 想要这个 10%，你就得这一回合里既砍一刀又放一个术法。
>
> ⚠️ 触发是**一次性**的：`zhoutianActive` 置位后本回合不再重复触发。

## 4. 弹反微操：回合制里的动作游戏

这是本作与普通卡牌游戏**最大的差异点**，也是"打击感"的第一来源。

### 4.1 判定条——一条从左往右跑的游标

```
时间轴（总计 1050 ms）
├──────────────┼──────────────────────────────┤
│  前摇 350ms  │      判定窗 700ms            │
│   ▓ 红区 ▓   │       ██ 金区 ██             │
└──────────────┴──────────────────────────────┘
   按下 = 过早        按下 = 完美弹反
   伤害减免 60%       伤害全免 + 追击
```

| 你按下时的位置 | 判定结果 | 效果 |
|---|---|---|
| 红区（< 350ms） | **过早（early）** | 伤害 **× 0.4**（即减免 60%），无追击 |
| 金区（350–1050ms） | **完美弹反（perfect）** | **伤害 = 0**，并触发**追击** |
| 游标跑完仍未按 | **未格挡（miss）** | 挨**满伤害** |

> 判定函数是纯函数：`judgeParry(elapsedMs)`——完全可单测、可回放。

### 4.2 完美弹反的奖励

一次成功弹反给你**三份回报**：

1. **伤害全额免疫**（本次敌方攻击 dmg = 0）
2. **追击**：立刻反击首发敌人，伤害 = **有效攻击力 × 0.5**（无消耗）
3. **回 1 点阴炁** + 屏幕中央砸下 92px 金色「**反弹**」水墨字

### 4.3 "大雪"节气的特殊规则

若本局炁候抽中**大雪**，`forceParry = true`：

> **所有格挡自动升级为完美弹反，无需卡时机。**

这是**新手友好 / 操作辅助**型节气。抽到它，你就把这一局当作纯策略局打。

### 4.4 这不是纯反应游戏

关键设计：**你可以选择不按**。

| 决策 | 场景 |
|---|---|
| **不按** | 这个敌人伤害很低，我懒得按，省下注意力 |
| **提前按** | 我预判它马上要打——虽然会亏，但保底减免 60% |
| **卡金区按** | 满额收益，但需要练 |

对**手残玩家**：你依然能玩，只是每次挨打都吃亏一点；
对**操作玩家**：练到金区连按，你能打出"零受伤通关"。

### 4.5 敌方招式是"预先公示"的

改版后，敌人头顶的公示升级为一张完整的**招式卡**——你不仅知道它要打什么，还知道**打多疼、要花多少势、是什么品阶**：

```
      ◈ 霜降·冰魇
┌──────────────┐
│ [杀] 绝息·冰封  │   ← 品阶徽章（常/技/凶/杀）+ 招式名
│   霜降绝杀     │   ← 招式说明
│  ●●●●○       │   ← 势资源：够不够出这招
└──────────────┘
```

**读招式卡的三层信息**：

| 看什么 | 得到什么情报 | 该怎么应对 |
|---|---|---|
| **品阶徽章** | `杀`=最高危，`凶`=高危 | 杀招必须弹反，凶招建议弹反 |
| **招式说明** | 是攻击 / 加盾 / 挂状态 | 挂状态的要优先打断（比如夺炁） |
| **势圆点** | 它下回合出不出得了大招 | 势不足时会「回气」，这是你的**安全窗口** |

> 这意味着弹反不是"盲猜时机"，而是"**读招 + 报点**"。
> 你会逐渐学会：哪个招式前摇长、哪个标红是暴击型要优先弹、
> 哪只敌人这回合势不够——**可以放心输出**。

## 5. 三大架势：三种完全不同的打法

架势可以**局内切换，每回合一次**（消耗本回合行动）。这是本作**策略深度**的主要来源。

### 5.1 体修 · 连击蓄势

| 项目 | 内容 |
|---|---|
| **核心** | 每张**物理牌**攒 1 层「**势**」（上限 **10** 层） |
| **每层收益** | 该架势下物理伤害 **+12%**（`1 + 势层数 × 0.12`） |
| **终局技** | **10 层 → 「破军」**：下一张物理牌造成 `有效攻击力 × 势层数` 的**真实伤害**（无视防御），消耗全部势 |
| **玩法** | 攒 → 憋 → 一刀清屏 |

**破军的数学有多夸张**（以陆青崖 庚金 + 唐刀为例）：

```
有效攻击力 = 22（角色）+ 12（唐刀）= 34
10 层破军伤害 = 34 × 10 = 340 点真实伤害
```

对比：砍一张「斩风」（×1.0）在申月（金旺 +25%）下约 **43 × 0.84 ≈ 36** 点。
**破军是普通攻击的 9 倍以上，且不吃防御、不吃刮痧。**

> ⚠️ **破军只在「体修」架势下解锁**。第 11 层的势不会累积（上限硬卡在 10）。

### 5.2 法修 · 五行轮转

| 项目 | 内容 |
|---|---|
| **核心** | 按**五行相生**顺序连续出术法牌 |
| **相生顺序** | **木 → 火 → 土 → 金 → 水 → (木)** |
| **连携收益** | 下一张术法**费用减半**（向上取整）＋ **伤害 ×1.5** |
| **额外能力** | 相克可**打断**敌方蓄力并附加**虚弱** |
| **玩法** | 满屏五行符文连环炸裂 |

**相生的实感**：你先打「青木诀」（木），下一张「离火咒」（火）就吃满减费与 1.5 倍——**这就是一条连携链**。

**相克表（打断敌方蓄力用）**：

```
木 克 土      土 克 水      水 克 火      火 克 金      金 克 木
```

**五行伤害的相互修正**（全架势通用）：

| 情形 | 倍率 |
|---|---|
| 我的五行**克**敌人 | **×1.25** |
| 我被敌人五行**克** | **×0.8** |
| 其余 | ×1.0 |

> 所以打 BOSS 前先看它的五行（惊蛰·春雷兽 = 木，霜降·冰魇 = 水），
> 用克它的术法（金克木、土克水）能多拿 25%。

### 5.3 散修 · 刀尖舔血

| 项目 | 内容 |
|---|---|
| **核心** | **阴阳炁差值越大，越强**（差值上限 **8**） |
| **暴击率** | 基础 15% + **差值 × 4%**（差值 8 时 = +32%） |
| **暴击伤害** | 基础 150% + **差值 × 8%**（差值 8 时 = +64%） |
| **替代比例** | **1:1**（全架势唯一） |
| **终局技** | 差值 **≥6** → 「**剑走偏锋**」：本回合**伤害 ×2.0**，但**回合结束自损当前血量 30%** |
| **玩法** | 极致心跳的数字豪赌 |

**算一笔账**（谢无咎 丙火 + 锏，基础攻 25+18 = 43）：

```
差值 8 时：
  暴击率 = 15% + 32% = 47%
  暴击倍率 = 150% + 64% = 214%
  剑走偏锋额外 ×2.0

单张「崩拳」（×2.0）在暴击 + 剑走偏锋下：
  43 × 2.0 × 1.1（得令/月令类） × 2.0 × 2.14 ≈ 400+ 点
```

代价：回合结束 **自损当前血量 30%**。血越少越危险——**这就是"刀尖舔血"**。

### 5.4 架势对比速览

| | 体修 | 法修 | 散修 |
|---|---|---|---|
| **节奏** | 慢热，越打越强 | 连携，链条不断 | 心跳，差值维持 |
| **最强一击** | 破军（真伤 ×10） | 相生链尾张（×1.5 叠乘） | 剑走偏锋暴击（×2 叠暴伤） |
| **最怕** | 撑不到 10 层就被秒 | 手牌五行断链 | 血线被压到 30% 以下 |
| **替代比例** | 2:1 | 2:1 | **1:1** |
| **适配角色** | 陆青崖（默认） | 苏绛雪（默认） | 谢无咎（默认） |

## 6. 伤害是怎么算出来的

理解这一段，你就理解了这个游戏的全部数值逻辑。

### 6.1 七阶段结算管线

```
阶段 1  基数        有效攻击力 = 角色攻击力 + 兵刃加成
阶段 2  卡牌倍率    基数 = ceil(有效攻击力 × 卡牌 mul) + 固定加值
阶段 3  收集修饰器  装备 / 月令 / 架势 / 十神 / 相克 / 节气 / 炁贯周天
阶段 4  连乘        总倍率 = 所有 mul 修饰器连乘
阶段 5  暴击        暴击率与暴击倍率（见 §5.3 / §13）
阶段 6  减伤        防御软化 + **刮痧下限**
阶段 7  护盾        先扣护盾，再扣血
```

### 6.2 防御减伤公式

```
实际伤害 = 伤害 × (1 − 防御 / (防御 + 120))
```

这是**软化型**减伤，不存在"100% 免伤"：

| 敌人防御 | 实际收到 | 减伤幅度 |
|---|---|---|
| 4（焦躁鬼） | 96.8% | 3% |
| 8（加班怨灵） | 93.8% | 6% |
| 15（霜降·冰魇） | 88.9% | 11% |

> 配合「破甲」状态（减防）能让这一项进一步放大收益。

### 6.3 刮痧下限：机制的地基

这是本作最重要的一条**反滥用规则**：

| 条件 | 结果 |
|---|---|
| 有效攻击力 **< 敌方防御 × 1.5** | 伤害被压到 `raw × 10%` |

**翻译成人话**：如果你的攻击力撑不起来，**再花哨的连携、再高的暴击倍率、再完美的五行相生，全都变成刮痧。**

这是设计上的"**数值是地基，机制是高楼**"——防止玩家靠堆机制无视数值构筑。

### 6.4 "性命双修"——一条写进类型系统的铁律

所有伤害修正被抽象为三种算子：

| 算子 | 含义 | 谁可以用 |
|---|---|---|
| `addBase` | 直接加在**基础攻击力**上 | **只有装备（兵刃）** |
| `addFlat` | 加在基数之后的固定值 | 少数来源 |
| `mul` | 乘算倍率 | 架势 / 命格 / 节气 / 月令 / 相克 / 周天 |

**铁律**：`addBase` 只有装备能用。架势、命格、节气、月令**任何其他来源**若尝试 `addBase`，**运行时直接抛错**。

> 为什么这么设计？
> ① 因为**全是乘法**，五层变量的计算**顺序不影响结果**——从根上消灭了一整类顺序依赖 bug。
> ② 因为加法只发生在两处（装备加成、卡牌基数），数值不会失控膨胀。
>
> 如果你想验证这条铁律真的在生效，跑一句即可：
> `grep -rn "addBase" src/game/engine/damage.ts` 会看到断言函数 `assertNoIllegalAddBase`。

### 6.5 一个完整的算例

**场景**：陆青崖（庚金，攻 22）配 **唐刀（+12）** + **离火镜**，架势**体修**，**势 5 层**，本局月令**申月·金旺**，用「劈山」（物理 ×1.6）打**霜降·冰魇**（防 15）。

```
① 有效攻击力 = 22 + 12 = 34
② 基数 = ceil(34 × 1.6) = 55
③ 收集修饰器：
   · 得令（庚金 == 申月金）        ×1.1
   · 金旺·兵刃（物理牌）           ×1.25
   · 势 5 层（体修）              ×1.6      （1 + 5×0.12）
   · 无相克（物理牌无五行）
④ 总倍率 = 1.1 × 1.25 × 1.6 = 2.2
   → 55 × 2.2 = 121
⑤ 未暴击 → ×1.0
⑥ 减伤 = 121 × (1 − 15/135) = 121 × 0.888 ≈ 107.5
   刮痧判定：34 < 15 × 1.5 = 22.5 ？否 → 不刮痧
⑦ 护盾 20 先扣 → 护盾 0，实伤 87.5 → 取整 87
```

**最终：87 点伤害**，附魔「赤焰斩」再追加一段火行伤害并挂 2 层灼烧。

## 8. 奥义卡：两张牌合成一张

**奥义卡不占卡池**——它不是卡表里的第 27 种牌，而是**运行时产物**。

### 8.1 合成规则

| 条件 | 说明 |
|---|---|
| **同属性** | 两张牌必须同"属性"才能合 |
| 属性怎么算 | 物理牌 → `physical`；术法/功能牌 → 它的五行 |
| **同名不可合** | 两张「斩风」不能合并 |
| 结果 | 伤害 = **(A.mul + B.mul) × 1.5** |

### 8.2 奥义卡的继承规则

| 字段 | 继承方式 |
|---|---|
| 消耗 | A + B 之和 |
| 段数 | `max(A.hits, B.hits)` |
| 群体 | A 或 B 任一为群体 → 群体 |
| 附加状态 | 优先取 A，否则取 B |

### 8.3 为什么强

| 打法 | 普通出两张 | 合并奥义 |
|---|---|---|
| 两张「离火咒」（各 ×1.4，阴 2 各） | 2.8 倍率，耗 4 阴，**占 2 次出牌** | **4.2 倍率**，耗 4 阴，**只占 1 次出牌** |

> **不消耗额外回合**是关键词：奥义卡合并后**直接结算**，等于白赚一次出牌机会。
> 你这一回合理论上可以打出"奥义 + 另一张牌"的组合拳。

### 8.4 怎么操作

- **触屏**：第一张牌点一下选中 → 再点一张可合并的牌 → 自动合成并结算
- **桌面**：同样支持点击选中（选中一张后，能合并的牌会亮**松花绿**边框）
- **合并按钮**：底部「合并奥义 ×1.5」按钮，选中一张后若存在合法配对即高亮

## 9. 破绽：给下一回合埋的雷

### 9.1 触发条件

**回合结束时**，若满足任一条件，就给**随机一个存活敌人**挂上「破绽」：

| 条件 | 门槛 |
|---|---|
| 本回合连击段数 | **≥ 3 段** |
| 本回合五行相克命中次数 | **≥ 1 次** |

### 9.2 破绽的效果

被标记的敌人会亮起**金色光圈 + 「破绽」角标**（脉冲动画）。

下回合你对它打出**首张攻击牌**（非群体）时：

| 效果 | 说明 |
|---|---|
| **必定暴击** | 无视暴击率判定 |
| **转为真实伤害** | **无视防御、无视刮痧下限** |

打完即消耗破绽（`freeze`/`flaw` 这类一次性状态在命中时移除）。

### 9.3 实战意义

> 破绽是"**用连击换爆点**"的机制。
>
> 「连刺」（3 段 ×0.45）单独打很弱（总倍率 1.35），但**它能立刻凑满 3 段连击触发破绽**。
> 下一回合你对被标记的敌人打一张「崩拳」（×2.0），直接变成一个**必定暴击的真实伤害核弹**。
>
> **这是"低倍率多段牌"的核心价值所在**——它们不靠伤害，靠"刷条件"。

## 10. 装备与附魔：9 种招式

### 10.1 双槽装备

战前在「编队 · 命盘」里配置，**两个槽位**：槽 A 装兵刃，槽 B 装法器（也可以都装兵刃/都装法器）。

### 10.2 兵刃（3 件，唯一能加基础攻击力的装备）

| 名称 | 攻击加成 | 段数加成 | 说明 |
|---|---|---|---|
| **唐刀** | **+12** | — | 直刃厚重，一刀两断 |
| **锏** | **+18** | — | 无刃钝器，靠质量砸开护甲。**最高基础攻击** |
| **苗刀** | **+8** | **+1 段** | 长柄窄刃，走偏锋。**唯一加段数的兵刃** |

### 10.3 法器（3 件，加炁上限 + 五行附魔）

| 名称 | 炁上限 | 五行 | 附魔特效 |
|---|---|---|---|
| **离火镜** | **+4** | 火 | 灼烧 |
| **坎水佩** | **+4** | 水 | 霜寒（减速 + 破甲） |
| **五雷令** | **+4** | 金 | 麻痹 + 击退 |

### 10.4 九种附魔招式（兵刃 × 法器）

| 兵刃 ＼ 法器 | 离火镜（火） | 坎水佩（水） | 五雷令（金） |
|---|---|---|---|
| **唐刀** | **赤焰斩** ×0.5 灼烧2 | **霜寒斩** ×0.5 霜寒1 | **奔雷斩** ×0.5 麻痹1 |
| **锏** | **烈焰锏** ×0.6 灼烧3 | **玄冰锏** ×0.6 霜寒2 | **雷震锏** ×0.6 破甲2 |
| **苗刀** | **火舞苗刀** ×0.4 灼烧1 | **霜刃苗刀** ×0.4 霜寒1 | **电光苗刀** ×0.4 麻痹1 |

**附魔是怎么触发的**：打出**物理牌**时，额外追加一段**技法伤害** =
`floor(有效攻击力 × 该卡倍率 × 附魔 mul)`，附带对应状态。

> 也就是说「赤焰斩」不是一张牌，而是**你的普攻自动变名 + 变色 + 多打一段**。
> 唐刀 + 离火镜 → 你每次物理攻击都会额外烧对面一下。

### 10.5 三大流派（按兵刃/法器数量）

| 流派 | 配置 | 特色 |
|---|---|---|
| **阴阳合契** | 1 兵刃 + 1 法器 | 物理 + 附魔双属性，**有附魔招式**（上表 9 种） |
| **五运阴阳** | 2 法器 | 炁上限 +8，术法续航最强，法修首选 |
| **纯阳武圣** | 2 兵刃 | **无限叠加「纯阳势」**，见下 |

### 10.6 纯阳武圣：终极技「开天」

双兵刃时，每打出一张物理牌累积 **1 层纯阳势**（**无上限**）：

| 项目 | 数值 |
|---|---|
| **每层加成** | 攻击 **+3%**（`1 + 层数 × 0.03`） |
| **终极技** | 攒满 **50 层** → 下一张物理牌变成「**开天**」 |
| **开天伤害** | `有效攻击力 × 50` 的**纯粹真实伤害** |

**算例**（谢无咎 攻 25 + 锏 18 + 苗刀 8 = 51）：

```
开天 = 51 × 50 = 2550 点真实伤害
```

> 这是**理论上的最高伤害**，代价是你要打 50 张物理牌——通常是长线 BOSS 战的解法。
> 50 层时每层 +3% 已经让普攻变成 ×2.5，本身也不弱。

## 11. 五层变量联动

这是企划的核心骨架：**五层变量逐层叠加，每一层都真实生效**。

| 层 | 变量 | 变化频率 | MVP 状态 |
|---|---|---|---|
| **① 月令**（地支） | 决定"当令五行"，影响五行旺衰 | **每局随机 1 个** | 12 条全实装 |
| **② 炁候**（节气） | 全局战场规则修正 | **每局随机 1 个** | 24 槽位，实装 8 个 |
| **③ 十神**（命格） | 角色固定，1 主星 + 1 辅星 | 角色决定 | 10 条留位，实装 6 个 |
| **④ 架势** | 局内可切换（每回合 1 次） | 玩家实时决定 | 3 个全实装 |
| **⑤ 装备** | 双槽组合，战前预设 | 玩家决定 | 3 兵刃 + 3 法器 |

### 11.1 月令（12 地支）

| 月令 | 五行 | 效果 |
|---|---|---|
| **寅月 / 卯月** | 木旺 | 木行术法 **+25%**，金行术法 **−20%** |
| **辰月 / 未月 / 戌月 / 丑月** | 土旺 | 防御/护盾 **+30%**，所有术法消耗 **+1 炁** |
| **巳月 / 午月** | 火旺 | 火行术法 **+25%**，水行术法 **−20%** |
| **申月 / 酉月** | 金旺 | **物理攻击 +25%**，木行术法 **−20%** |
| **亥月 / 子月** | 水旺 | 水行术法 **+25%**，土行术法 **−20%** |

### 11.2 得令 / 失令（月令与角色本命五行的关系）

| 状态 | 判定 | 效果 |
|---|---|---|
| **得令** | 角色本命五行 **==** 月令五行 | 每回合自动 **+1 阳炁 +1 阴炁**，全技能 **×1.1** |
| **失令** | 角色本命五行 **被**月令五行**所克** | 每回合**首张牌消耗 +1 炁**，暴击率 **−10%** |
| **平** | 其余（含相生、我克月令） | 无修正 |

**举例**：本月是**申月·金旺**（金）
- **陆青崖（庚金）** → 金 == 金 → **得令** ✅（强烈推荐本月用他）
- **苏绛雪（癸水）** → 金生水（月令生我）→ 平
- **谢无咎（丙火）** → 火克金（我克月令）→ 平

> ⚠️ **失令在 MVP 中跑不到**：因为初始 3 个角色分别是金/水/火，没有木行角色，
> 而会被木所克的是……等等，**木克土**，MVP 无土行角色，所以失令分支**不会被自然触发**。
> 但**代码逻辑已完整实现并单测覆盖**（构造木行角色 + 申月金旺即可复现）。

### 11.3 节气（8 个已实装）

| 季 | 节气 | 战场效果 | 机制类型 | 物候粒子 |
|---|---|---|---|---|
| 春 | **惊蛰** | 本局**首张攻击牌伤害 ×1.5，但该牌消耗翻倍** | 资源博弈 | 落叶 |
| 春 | **春分** | **调息效率 ×1.5**（阴阳转换更划算） | 资源流转 | 花瓣 |
| 夏 | **芒种** | **每回合必须打出 ≥2 张攻击牌**，否则自扣 **10% 最大生命** | **强制进攻** | 麦穗 |
| 夏 | **大暑** | 所有伤害 **+20%**，但**治疗与护盾 −50%** | 数值修正 | 火星 |
| 秋 | **白露** | 术法牌额外消耗 **20% 阴炁**，但命中**必附加霜寒** | Debuff 附加 | 霜 |
| 秋 | **霜降** | **暴击必附加「冻结」**，但暴击伤害**固定为 150%** | 控制 | 霜 |
| 冬 | **大雪** | **所有格挡自动升级为弹反**（无需卡时机） | **操作辅助** | 雪花 |
| 冬 | **冬至** | 每回合开始，阴阳炁自动**向低的一脉补充，且补充量 ×2** | 资源流转 | 雪花 |

**逐条解读：**

- **惊蛰**：只有**本局第一张**牌吃 ×1.5——但它消耗翻倍。你愿意为开局重拳付双倍炁吗？
- **春分**：调息从 2:1 变成约 1.33:1，**散修和法修的续航大涨**。
- **芒种**：**本作唯一的"硬约束"节气**。它逼你放弃纯防御/纯攒势打法，每回合至少碰两次攻击牌。
- **大暑**：白刃战节气。伤害全体 +20%，但**所有回复和护盾砍半**——别想苟。
- **白露**：术法流的高投入高回报——阴炁多花 20%，但你的每一个术法都给敌人挂霜寒。
- **霜降**：暴击**必定冻结**（敌人下回合不能动），代价是暴击伤害固定在 150%（伤官流的 200% 被拉平）。**控制换伤害**。
- **大雪**：把操作难度归零，**手残玩家的福音**。
- **冬至**：被动维稳，每回合自动补炁——**差值保持型散修会很喜欢它**。

> **节气是"每局随机"的**，也是本作**重复可玩性**的核心：同一关卡，抽到芒种你要抢攻，抽到大雪你可以慢慢运营。

### 11.4 五层怎么叠在一起

以 **陆青崖 + 唐刀/离火镜 + 体修 + 申月 + 惊蛰** 打一张「劈山」为例：

```
装备层：唐刀 +12 攻击              → 有效攻击力 34
月令层：得令 ×1.1 + 金旺·兵刃 ×1.25
架势层：势 5 层 ×1.6
节气层：惊蛰首牌 ×1.5
———————————————————————————————————
总倍率 = 1.1 × 1.25 × 1.6 × 1.5 = 3.3
```

> 注意：**乘法交换律保证这四层谁先谁后都不影响结果**。这就是 §6.4 那条铁律的价值。

## 12. 异常状态一览

> **设计铁律**（设计哲学 §6.3「禁止无响应系统」）：
> 每一个列在这里的状态，**引擎里都必须有真实效果**，并且**双向生效**——
> 你对敌人挂的灼烧，和你被挂的灼烧，走的是同一套结算。
> 不允许存在「只对玩家有效」或「只是显示但没效果」的装饰性状态。

| 状态 | 图标色 | 效果 | 来源 |
|---|---|---|---|
| **灼烧**（burn） | 朱红 | 回合开始按 `层数 × 4` 扣血（**敌我双向结算**） | 离火镜 / 离火咒 / 焚天焰 / 赤焰斩 |
| **霜寒**（frost） | 月白 | **减速 + 破甲** | 坎水佩 / 寒冰咒 / 白露节气 |
| **冻结**（freeze） | 月白 | **下回合无法行动** | 霜降节气 / 霜降·凝华 |
| **虚弱**（weak） | 松花绿 | **攻击伤害降低**，每层 −15%，上限 −45% | 藤蔓缚 / 崩拳 / 焦躁鬼「怨念缠身」/ 冰魇「忘川低语」 |
| **破甲**（armorBreak） | 琥珀 | **防御降低**，每层 −15% | 劈山 / 锐金斩 / 破甲击 / 雷震锏 |
| **麻痹**（paralyze） | 金 | 行动受扰 | 五雷令 / 奔雷斩 / 电光苗刀 |
| **沉默**（silence） | 石青 | **封锁术法牌**（预留，尚未实装） | 金吾卫「锁链缠足」 |
| **破绽**（flaw） | 明黄 | **下回合首张攻击牌必暴击 + 真实伤害** | 连击 ≥3 / 相克命中 |

**虚弱与破甲的实际算法**（已实装于 `engine/damage.ts`）：

```
有效防御 = 防御 × max(0, 1 − 破甲层数 × 0.15)
攻击削减 = min(0.45, 虚弱层数 × 0.15)      // 作为 mul 算子接入伤害管线
```

> 举一反三：**虚弱对高倍率敌人最有效**。
> 冰魇「绝息·冰封」×2.6，如果你先给它挂 3 层虚弱（−45%），
> 这一击就少打掉你半条命。**减伤的价值随敌人倍率线性增长。**

特殊机制状态（不进敌人状态栏）：

| 名称 | 效果 |
|---|---|
| **势**（体修） | 每层物理伤害 +12%，10 层解锁破军 |
| **势**（敌人） | 敌人的出招资源，不足则本回合只能回气。**上不封顶显示为招式卡上的圆点** |
| **纯阳势**（双兵刃） | 每层攻击 +3%，50 层解锁开天 |
| **炁贯周天** | 本回合伤害 ×1.1 |

## 14. 敌人与战役

### 14.0 敌人也有「势」——本作的敌方资源系统

和玩家一样，心猿不是随便出招的。每只心猿都有一个**「势」资源**（`shi`，上限 `shiCap`）：

- 每次出招**消耗势**（招式的 `cost`）
- 势不够时，这一回合它只能**「回气蓄势」**（势 +1），静静站着不出手
- 势每回合自动回复，所以**高威胁招式会间歇性出现**，而不是每回合都砸脸

这意味着战斗有**节奏起伏**：你能从招式卡上的势点数（●●●○○）预判它下回合出不出得了大招。

> **设计意图**（对齐设计哲学 §6.3「禁止无响应系统」）：
> 敌方资源是玩家可以**观察、预判、利用**的信息。
> 你甚至能通过「让它一直凑不齐势」来压制它的杀招——这是主动的战术空间。

### 14.1 心猿的阴阳两面

**世界不是非黑即白的。** 心猿分两类，它们的设计取向截然不同：

| 阵营 | 本质 | 设计取向 | 成员 |
|---|---|---|---|
| **阴执** | 都市负面戾气的具象化 | 可以晦暗暴烈，但**不血腥恐怖**，是「心理问题的怪物」而非恐怖片恶鬼 | 焦躁鬼 / 加班怨灵 / 贪嗔蠹 |
| **阳华** | 被正气与节令淬炼出的精怪 | **绚烂、华贵、有尊严**，一眼看去「它不是坏东西，只是在考你」 | 金吾卫 / 惊蛰·春雷兽 / 霜降·冰魇 |

> 春雷兽是「惊蛰」的第一声雷，是**天地正炁**，不是恶魔；
> 冰魇是「霜降」的凝华，是**仙灵**，美得让人忘记害怕；
> 金吾卫是长安城旧日的巡夜卫士，**它不害人，只认「规矩」**。
>
> 这样做的好处：玩家面对的不是「一坨要打的黑暗」，而是**有立场、有气质的对手**，
> 胜利才有「切磋」的酣畅感，而不是「除魔」的压抑感。

### 14.2 六只心猿（完整数值）

| 名称 | 阵营 | 形 | 五行 | 气血 | 攻击 | 防御 | 势上限 | 特殊行为 |
|---|---|---|---|---|---|---|---|---|
| **焦躁鬼** | 阴执 | 游魂 | 火 | 110 | 16 | 6 | 3 | 抓挠 → 躁意上涌（自蓄势）→ 怒咬 → 怨念缠身（挂虚弱） |
| **加班怨灵** | 阴执 | 游魂 | 土 | 150 | 18 | 10 | 4 | 僵坐（+24 盾）→ 重压 → 絮叨 → 夺炁 → 全屋熄灯（AOE） |
| **贪嗔蠹** | 阴执 | 虫 | 木 | 130 | 20 | 5 | 4 | 啃噬 → 虫群（AOE）→ 结茧（蓄势 +2）→ **化蝶噬心（×1.8）** |
| **金吾卫** | **阳华** | 兽 | 金 | 175 | 20 | 12 | 4 | 立盾（+28 盾）→ 横刀 → **金吾大辟（×2.0）** → 锁链缠足（封术法） |
| **惊蛰·春雷兽** | **阳华** | 兽 | 木 | **380** | 26 | 16 | 5 | 引雷（蓄势 +2）→ 春雷落 → 雷震四方（AOE）→ 盘角（+40 盾）→ **万雷归一（×2.4）** |
| **霜降·冰魇** | **阳华** | 龙 | 水 | **430** | 28 | 19 | 5 | 冰锥 → 凝霜（+46 盾）→ 霜噬（AOE）→ 忘川低语（挂虚弱）→ **绝息·冰封（×2.6）** |

**读表要点**：

- **杂兵不是软柿子**：焦躁鬼 110 血在改版前只有 60。它现在能真的打死你。
- **金吾卫是「守门员」**：175 血 + 12 防御 + 28 盾的「立盾」，硬得离谱。
  它检验的是你的**穿透能力**——破甲、真实伤害、相克。
- **双 BOSS 是 810 血**（380 + 430），不是改版前的 400。第四战是真正的**耐力考试**。
- **杀招的倍率**：冰魇「绝息·冰封」×2.6 打 72 点基础，**不弹反基本就是半条命**。

### 14.3 敌人的意图以「招式卡」公示

改版后，敌人头顶不再只是一行字，而是一张**招式卡**：

```
┌──────────┐
│ [杀] 万雷归一 │   ← 品阶徽章 + 招式名
│   倾泻全部蓄势 │   ← 招式说明（note）
│  ●●●●○    │   ← 势资源：够不够出这招
└──────────┘
```

**四种意图类型**：

| 意图 | 表现 | 结算 |
|---|---|---|
| **攻击（attack）** | 朱红招式名 | 造成 `damage` 点伤害 |
| **群攻（aoe）** | 朱红招式名 | 同上 |
| **防御（guard）** | 招式卡显示护盾值 | 给自己加 `selfShield` 点护盾 |
| **增益（buff）** | 招式卡显示「蓄势 +N」 | 累积蓄力，自身蓄势 +N |
| **减益（debuff）** | 招式卡显示负面效果 | 给你挂上 `inflict` 里指定的异常状态 |

**四个品阶**（招式卡左上角的徽章，颜色区分危险度）：

| 品阶 | 徽章 | 颜色 | 含义 |
|---|---|---|---|
| `base` | **常** | 灰褐 | 普通招式，可以扛 |
| `art` | **技** | 石青 | 有机制的招式（挂状态、加盾） |
| `dire` | **凶** | 琥珀 | 高伤害，**建议弹反** |
| `kill` | **杀** | 朱红 | 杀招，**必须弹反或提前处理** |

> ⚠️ **蓄力的真实结算**：敌人蓄力后，**下一次攻击会一次性倾泻所有蓄力层数**，然后清零。
> 所以看到敌人「蓄势 ×2」时，下一次攻击是 **×3 伤害**——这是你必须**优先弹反**的回合。
>
> 注意区分：**蓄力层数（chargeStacks）** 与 **势（shi）** 是两个不同的东西。
> 蓄力是「伤害放大的燃料」，势是「出招的通行费」。贪嗔蠹的「结茧」是蓄力，金吾卫的「势」是资源。

| **1** | 第一战 · 烟火长安 | 焦躁鬼 + 金吾卫 | 出牌 / 阳炁获取 / **遇见「规矩」** |

| **合并奥义** | 点第一张选中 → 点第二张（同属性，会亮绿边）→ 自动结算 |
| **切换目标** | 点敌方立绘 |
| **阴阳逆转（调息）** | 点「**☯ 阴阳逆转**」（自动判断转换方向） |
| **切换架势** | 点架势条上的按钮（每回合限 1 次） |
| **结束回合** | 点「结束回合」（朱红底金边按钮） |
| **弹反** | 敌方回合时，游标进金区点「**格挡**」大按钮（金色发光） |
| **撤退** | 天时条右上角「撤退」回主界面 |

> **手牌是扇形重叠的**（像《月圆之夜》）：牌越多，重叠越多（6/26/40px 三档）。
> 点选时那张牌会**弹出放大**，从牌堆里「跳出来」。牌太多时手牌区可**横向滑动**。

### 15.4 敌方回合的界面变化

**关键设计**：敌方回合时，**手牌区整体被格挡面板接管**。

```
┌────────────────────────────────────┐
│  ▓▓▓▓▓▓▓░░░░░░░ 游标从左往右跑      │  ⑧ 判定条（330 × 24）
│     红区 350ms  │  金区 700ms       │
│  「蓄力中…等金色」/「此刻！按下去」  │
│  ╔══════════════════════════════╗  │  ⑨ 格挡大按钮（340 × 128）
│  ║          格    挡             ║  │  金区时放大 + 金光
│  ╚══════════════════════════════╝  │
└────────────────────────────────────┘
```

> 手牌暂时"消失"是为了**把注意力全部压到弹反上**——这是把回合制变成动作游戏最重要的一处 UI 决策。

### 15.6 特效强度分级

设置项「特效强度」三档（存档字段 `fxLevel`）：

| 档位 | 粒子上限 | 溅射规模 | 物候生成间隔 |
|---|---|---|---|

## 16. 命理复盘：结算页怎么看

结算页不是一堆评分，而是**"你这局怎么打出来的"回放**。

| 数据 | 含义 |
|---|---|
| **得令 / 失令** | 本局月令与角色的关系，以及触发的效果 |
| **回合数** | 打了多少回合 |
| **出牌数** | 总共出了多少张牌 |
| **最高连击** | 单回合最高连击段数 |
| **相克命中** | 单回合最高五行相克命中次数 |
| **最高单次伤害** | **单次打出的最高伤害**，并附**怎么打出来的**注解（如「劈山（得令·金旺·兵刃·势 5 层·惊蛰）」） |
| **弹反 / 完美弹反** | 总格挡次数 / 其中完美次数 |
| **十神触发** | 每个十神本局触发了几次（印章式计数） |

> **"最高单次伤害"的注解是分享欲的来源**：它会告诉你这一刀是哪些层叠出来的。
> 看到「2550 · 开天」和看到「87 · 劈山」完全是两种心情。

## 17. 进阶：五套成型打法

### 17.1 体修破军流（陆青崖）

**核心**：攒满 10 层势 → 破军一刀真伤。

**关键操作**：
1. 前期用便宜的物理牌刷势（「斩风」阳 1、「疾风刺」阳 1 还带抽牌）
2. 攒到 9 层时**停手**，等下回合打
3. 第 10 张物理牌自动触发破军 —— **注意：破军是"第 10 层的那张牌"触发的**

**为什么强**：破军不吃防御、不吃刮痧，**专治高防 BOSS**（霜降·冰魇 防 15）。

**注意**：势在换架势后**不会清空**，但只有体修架势下才能累积。

### 17.2 法修相生链（苏绛雪）

**核心**：木 → 火 → 土 → 金 → 水，每条链子上每张牌回本减半 + 伤害 ×1.5。

**关键操作**：
1. 手牌里排好五行顺序，**先手不要乱出**
2. 用「聚炁」「回气丹」保证阴炁够撑完整条链
3. 带**双法器**（坎水佩 + 五雷令）把阴炁上限顶到 18

**算例**：一张「离火咒」（阴 2，×1.4）在相生链里变成 **阴 1，×2.1** —— **性价比翻了一倍多**。

**克制**：抽到「白露」节气时术法多耗 20% 阴炁，需要更精打细算。

### 17.3 散修剑走偏锋（谢无咎）

**核心**：把阴阳差值保持在高位（≥6），吃满暴击率 + 暴伤 + 2 倍伤害。

**关键操作**：
1. **刻意制造差值**：多打物理牌（耗阳）少用阴炁
2. 差值 ≥6 时，你的输出直接 ×2
3. **回合结束前评估血量**：自损 30%，血少的时候慎用

**风险**：值越高越脆。血线被压到 30% 以下时，「剑走偏锋」的自损可能直接送你上路。
**破局**：反过来说，血量 <10% 时如果带七杀……（谢无咎没有）。

### 17.4 纯阳武圣流（谢无咎 + 双兵刃）

**核心**：锏 + 苗刀，堆 50 层纯阳势，开天 2550 真伤。

**关键操作**：
1. 苗刀 +1 段，让「连刺」「疾风刺」这类多段牌**额外刷势**（每张物理牌 +1 层，段数不影响层数——所以用最便宜的牌刷）
2. **首选「疾风刺」**：阳 1，还能抽 1 张牌，**刷势效率最高**
3. 50 层前，每层 +3% 已经让你普攻 ×2.5

**代价**：**没有法器 = 炁上限只有 10**，续航是最大问题。需要大量「聚炁」「回气丹」。

### 17.5 弹反流（任何角色）

**核心**：把每一次敌方攻击都变成完美弹反 —— **零受伤 + 每次白嫖一次追击**。

**关键操作**：
1. 记住游标节奏：**总 1050ms，前 350ms 是红区**
2. 盯着敌人头顶的**招式名**（它提前公示），心里数拍
3. 完美弹反回 1 阴炁，追击伤害 = 攻击 ×0.5 —— **练熟了，你甚至不太需要出牌**

**最强搭配**：抽到「大雪」节气（自动弹反），或带**坎水佩**（阴炁上限高，弹反回炁更有价值）。
