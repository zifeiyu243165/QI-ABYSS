# 《炁渊 · QI ABYSS》完整设计哲学文档

## ——我们为什么这样做，以及我们绝不做什么


## 序言：设计哲学的出发点

《炁渊》的一切设计决策，都从三个原点出发：

1. **文化不是皮，是骨。** 道教文化、命理学、二十四节气——这些不是贴在表面的花纹，而是决定玩法底层逻辑的骨架。如果去掉文化外衣后玩法依然成立，说明文化只是皮，那我们就失败了。
2. **爽感不是数值，是节奏。** “战斗爽”不来自伤害数字后面多几个零，而来自“濒死反杀”“完美弹反”“连锁滚雪球”这些**节奏事件**。玩家记住的永远是自己最惊险的那一波操作，不是面板上的攻击力。
3. **策略不是背板，是即兴。** 月令、炁候、十神、架势、装备、卡组——六层变量随机组合，逼玩家每局重新思考。没有“一套阵容打天下”，没有“抄作业就能赢”。

以下，从玩法、UI、人物、理念、文化深度、内部逻辑六个层面，逐一展开。


## 一、玩法设计哲学

### 1.1 核心信条：天时、地利、人和

《炁渊》的每一局战斗，都是三层博弈的叠加：

- **天时（月令+炁候）**：你无法选择的环境变量。本月金旺还是水旺？本局抽到“芒种”还是“大雪”？天时决定了你这局的**战略方向**。
- **地利（装备+架势+卡组）**：你战前构筑的选择。一物一法还是双物理？体修还是散修？《道德经》还是《阴符经》？地利决定了你这局的**战术手段**。
- **人和（十神+操作）**：你局内的每一次决策。什么时候弹反？什么时候切架势？先杀谁触发七杀？人和决定了你这局的**执行上限**。

**设计约束**：
- 天时（月令/炁候）对胜率的影响权重**不超过30%**。天时不利时，靠地利与人和仍可翻盘，但会打得更艰难、更需要精算。
- 地利（装备/架势/卡组）对胜率的影响权重**约占40%**。构筑是基本功，但不是全部。
- 人和（十神触发/操作）对胜率的影响权重**不低于30%**。操作和决策永远有空间改变战局。

**避免的负面约束**：
- ❌ 绝不设计“天时碾压”——没有哪个节气或月令能让某一方开局就赢。
- ❌ 绝不设计“唯一解构筑”——不存在某套装备组合在所有环境下通吃。
- ❌ 绝不设计“纯运气局”——偏财命格的额外抽牌有20%概率，但即使一次不触发，也不影响核心战术执行。

### 1.2 资源哲学：挨打也是战略

传统卡牌游戏中，“受击”是纯粹的负面事件——掉血、丢节奏、被动挨打。《炁渊》彻底翻转这个逻辑：

**“阴炁”的核心设计意图**：让“受击”变成一种**资源获取行为**。你挨打越多，阴炁攒得越快，下回合反打的资本越厚。

**设计约束**：
- 阴炁的获取量必须**略高于**阳炁的自然获取量（约1.2:1），让“卖血换蓝”在数学上划算。
- 但阴炁的**消耗效率必须略低于**阳炁（术法牌的平均伤害/消耗比约是物理牌的85%），防止“龟缩流”成为最优解。
- 格挡与弹反给予的阴炁奖励，必须**高于**单纯挨打（弹反额外+1阴炁），鼓励玩家主动操作而非被动承受。

**避免的负面约束**：
- ❌ 绝不设计“挨打就赢”的极端龟缩流——阴炁再多，也需要阳炁配合才能打出爆发。
- ❌ 绝不设计“受击无反馈”——每次挨打必须有明确的阴炁增长提示（月白流光注入计量条），让玩家清晰感知“我在攒资源”。

### 1.3 操作哲学：回合制里的“动作感”

《炁渊》本质是回合制，但每一回合内，玩家都有**即时操作窗口**：

- **弹反**：0.5秒的格挡窗口，卡准时机触发完美弹反。
- **连携QTE**：双指滑动合并同属性牌，不消耗额外回合。
- **调息时机**：在出牌前还是出牌后调息？影响本回合资源分配。

**设计约束**：
- 所有即时操作窗口**不强制**。手残党可以关闭“弹反”功能，改为自动格挡（但收益降低50%）。核心体验不依赖操作精度。
- 连携QTE的合并操作，**单手可完成**（滑动而非多指手势），确保手机端手感。
- 每回合的即时操作**不超过3次**，防止操作过载。

**避免的负面约束**：
- ❌ 绝不设计“必须弹反才能通关”的关卡——弹反是增益，不是门槛。
- ❌ 绝不让QTE的失败造成负面后果——合并失败只是退回原牌，不消耗费用，不扣血。
- ❌ 绝不用操作精度替代策略深度——“手速快”永远不能弥补“出牌顺序错”。

### 1.4 数值哲学：性命双修，铁律如山

**核心公式**：
> **最终伤害 = （基础攻击力 × 技能倍率） + （机制特效附加伤害 × 0.2）**

**破防阈值**：
> 若基础攻击力低于敌方基础防御力，所有机制特效（灼烧/冰冻/连击/暴击）只能造成**1点保底伤害**。

这意味着：一个攻击力100的角色打防御力150的敌人，哪怕技能倍率1000%、暴击率100%、灼烧叠了10层，最终伤害仍然趋近于**刮痧**。

**设计意图**：
- 机制（性）是放大器，不是替代品。没有基础数值（命），一切机制都是空中楼阁。
- 鼓励玩家**先堆命，再修性**——先保证攻击力达标，再考虑暴击/连击/属性克制。
- 呼应道家“性命双修”的核心理念：只修性不修命，是孤阴不生；只修命不修性，是独阳不长。

**设计约束**：
- 基础攻击力的成长曲线必须**陡峭**——每提升1级，攻击力增长8%~12%，让“练级”有明确的获得感。
- 机制特效的附加伤害公式中，**×0.2的系数不可动摇**。这是防止“机制白嫖”的底线。
- 允许“越级打怪”存在，但上限为**敌方防御力不超过己方攻击力的130%**。超过这个阈值，强制进入刮痧模式，逼玩家回去练级。

**避免的负面约束**：
- ❌ 绝不设计“纯机制流”角色——没有任何一个角色的技能组可以完全绕过基础攻击力。
- ❌ 绝不设计“无视防御”的廉价手段——所有无视防御的效果（如【开天】）都必须附带极高的使用代价（消耗50层“势”或大量炁）。
- ❌ 绝不让“氪金”直接兑换攻击力——付费只买皮肤和角色，不卖数值。

### 1.5 道家典籍卡组系统

#### 1.5.1 核心理念：以典入道，以道驭术

在《炁渊》中，**卡组不是“职业技能树”，而是一部道家典籍的玩法化演绎**。每个角色在战斗前选择一部典籍作为其“道枢”（即卡组核心），该典籍决定了：

- **卡牌的获取逻辑**（如何抽牌、弃牌、检索牌）
- **资源的使用方式**（炁的消耗/转化/储存规则）
- **战斗的节奏形态**（快攻/中速/控制/组合技）
- **终极奥义的设计方向**（该典籍哲学理念的极致体现）

**关键约束**：每部典籍的玩法机制，必须能在该典籍的原文中找到**至少三处理论依据**。不能凭空编造与典籍无关的机制。

#### 1.5.3 卡组与现有系统的联动

| 系统层级 | 与卡组的互动方式                                             |
| -------- | ------------------------------------------------------------ |
| **月令** | 不同卡组在不同月令下表现差异显著。如《阴符经》在申月金旺时可窃取更多物理资源；《清静经》在亥月水旺时净化效果翻倍 |
| **炁候** | 节气效果改变卡组核心机制运转。如“芒种”（强制进攻）对《道德经》极为不利，但若巧妙利用“反者道之动”的逆转机制，反而能打出惊人爆发 |
| **十神** | 十神命格与卡组哲学存在“共鸣”关系。七杀（击杀减费）与《阴符经》的“盗机”理念高度契合；正印（锁血保命）与《度人经》的“救赎”理念天然匹配 |
| **架势** | 卡组决定“带什么牌”，架势决定“怎么打”。同样使用《南华经》，体修架势侧重“齐物”转化物理牌，法修架势侧重“坐忘”弃牌换术法 |

**设计约束**：
- 每套卡组必须有一个**明确的“不擅长领域”**。《道德经》不擅长快攻，《抱朴子》不擅长控制，《清静经》不擅长爆发——没有全能卡组。
- 卡组之间的强度差异**不超过15%**，且每月随月令轮转，确保没有“永远下水道”的卡组。
- 任何卡组都可以与任何角色、任何架势、任何装备组合搭配——**没有强制绑定**。但不同组合的适配度不同，需要玩家自行探索。


## 二、UI设计哲学

### 2.1 核心信条：信息密度与视觉呼吸的平衡

卡牌游戏的UI面临根本矛盾：**需要展示的信息量极大**（手牌、炁量、敌方状态、节气效果、月令加成、十神触发、卡组机制……），但**屏幕空间有限**。

《炁渊》的解法：**分层展示 + 动态聚焦**。

**设计约束**：
- **第一层（常驻）**：手牌区、阴阳炁计量条、当前节气/月令图标、回合数、卡组标识。永远可见，不遮挡战场。
- **第二层（悬浮/点击展开）**：十神效果详情、装备附魔列表、五行相生相克表、卡组机制说明。需要时呼出，不需要时收起。
- **第三层（动态弹出）**：事件触发时（如七杀击杀、偏财抽牌、弹反成功、卡组机制触发），屏幕中央或对应角色旁弹出**短暂动画+文字提示**（0.8秒），随后自动消失。
- **第四层（结算复盘）**：战斗结束后，以“命理复盘”形式展开所有本局数据。

**避免的负面约束**：
- ❌ 绝不在主界面同时展示超过**7个信息模块**（米勒定律：人类短期记忆容量为7±2）。
- ❌ 绝不用“弹窗套弹窗”——任何二级信息都在当前面板内展开，不新开窗口。
- ❌ 绝不让“节气/月令/卡组”的图标遮挡角色立绘或手牌。

### 2.2 色彩哲学：五正色的功能化使用

中国传统五正色在UI中不仅是装饰，更是**功能标识**：

| 颜色          | 功能含义       | UI应用                                 |
| ------------- | -------------- | -------------------------------------- |
| **朱红**      | 阳炁/物理/火行 | 阳炁计量条、物理牌边框、火行术法牌底色 |
| **月白**      | 阴炁/术法/水行 | 阴炁计量条、术法牌边框、水行术法牌底色 |
| **琥珀黄**    | 金行/暴击/破绽 | 暴击数字、破绽光圈、金行术法牌底色     |
| **松花绿**    | 木行/回复/生长 | 治疗数字、木行术法牌底色               |
| **鸦青/缟素** | 土行/防御/背景 | 护盾特效、土行术法牌底色、战场底色     |

**设计约束**：
- 五行属性在UI中**必须有独立的颜色标识**，玩家扫一眼手牌就能识别属性。
- 颜色饱和度必须符合**中国传统色标准**（参考故宫博物院色谱），不得使用荧光色。
- 色盲模式：为每种五行增加**独立的纹理标识**（火行=火焰纹、水行=波浪纹、木行=藤蔓纹、金行=回纹、土行=龟裂纹），确保色盲玩家可辨别。

**避免的负面约束**：
- ❌ 绝不使用纯黑（#000000）作为背景——统一使用鸦青（#1A1F2B）或缟素（#E8E4D8）。
- ❌ 绝不用颜色传达**唯一信息**——每个颜色标识必须同时有文字/图标辅助。
- ❌ 绝不用红色表示“危险/警告”——红色在本作中是“阳炁/攻击/火行”的正面标识，避免语义冲突。

### 2.3 动效哲学：每一帧都有意义

《炁渊》的UI动效遵循**“信息传递优先，视觉炫技次之”**的原则：

- **炁量变化**：阴炁/阳炁增长时，计量条以**呼吸式脉冲**填充，而非线性滑动——让玩家感受到“气在流转”。
- **卡牌打出**：卡牌从手牌飞出时，沿**弧线轨迹**飞向目标，附带拖尾墨迹。物理牌轨迹更直、更快；术法牌轨迹更飘、更缓。
- **十神触发**：每个十神有**专属触发特效**。正印锁血=金色护法神虚影；七杀减费=血红色裂痕闪过；偏财抽牌=铜钱碰撞音效+金色粒子。
- **弹反成功**：屏幕边缘向中心收缩**金色水墨涟漪**，伴随“铮”的一声金属颤鸣，然后画面恢复正常。
- **卡组机制触发**：每套典籍卡组有专属视觉语言。如《道德经》触发时浮现**太极阴阳鱼**；《南华经》触发时化为**蝴蝶虚影**消散。

**设计约束**：
- 所有动效时长**不超过0.5秒**（终结技定格立绘除外，其为1.5秒）。
- 动效必须**可跳过**——长按屏幕任意位置加速所有动效至2倍速。
- 动效的音效与视觉必须**同步**——不能出现“画面已经结束了，音效还在响”的情况。

**避免的负面约束**：
- ❌ 绝不用动效**遮挡关键信息**——例如，十神触发特效不能挡住敌方血量或破绽标记。
- ❌ 绝不设计**不可跳过的**动画——包括终结技在内，所有动画均可跳过。
- ❌ 绝不用**闪烁频率超过3Hz**的动效——防止光敏性癫痫风险。


## 三、人物设计哲学

### 3.1 核心信条：命格即人格

《炁渊》的角色设计，**从命理学出发，而非从外观出发**。

每个角色的设计流程：
1. **先定日主**（本命五行）→ 决定其基础战斗风格倾向。
2. **再定十神**（主星+辅星）→ 决定其行为逻辑与战术定位。
3. **后定背景故事** → 解释其为何拥有这样的日主与十神。
4. **最后定外观** → 根据以上三点，设计符合中国传统色的二次元形象。

**示例**：
- **陆青崖**：庚金（刚锐之金）→ 七杀（暴戾之缚）+偏财（投机之获）→ 背景：游走生死边缘的散修刀客，越危险越强 → 外观：鸦青色大氅配朱红内衬，唐刀斜挎，眼神带一丝疯批。
- **玄微子**：癸水（润泽之水）→ 正印（仁义之护）+食神（绵密之锋）→ 背景：道门正宗出身的守护者，以柔克刚 → 外观：月白道袍配石青滚边，拂尘不离手，气质温润如玉。

**设计约束**：
- 每个角色的**日主与十神必须在其背景故事中有合理的性格映射**。不能出现“一个性格暴躁的角色却是正印命格”这种逻辑断裂。
- 角色的**战斗动作必须体现其日主特性**。庚金角色的刀法刚猛直接，癸水角色的术法流转绵密。
- 角色的**配色必须严格遵循五正色体系**，且主色与其日主五行对应。

**避免的负面约束**：
- ❌ 绝不设计“纯萌系”角色——所有角色都必须有**战斗的凌厉感**，即使是辅助角色，也要有“温柔但致命”的气质。
- ❌ 绝不设计“换皮角色”——两个角色即使同为火行、同为体修，其十神组合和战斗逻辑也必须完全不同。
- ❌ 绝不设计“无背景的立绘”——每个角色的服饰纹样、配饰、武器都有命理学依据。

### 3.2 角色成长哲学：局内定胜负，局外只修心

**核心原则**：角色在局外的成长，只解锁**新玩法**和**新外观**，不直接提升战力。

**局外成长内容**：
- **角色等级**：每级提升基础攻击/炁量上限**3%**（聊胜于无的幅度，10级累计约30%，但远低于局内残卷的加成）。
- **羁绊系统**：与特定角色共同出战达到一定次数，解锁**专属连携奥义**（新技能，非数值提升）。
- **修行残卷**：局内掉落，本局生效。可选择强化体/法/散某一方向，效果显著（如“体修残卷：每层势额外+2%攻击”）。

**设计约束**：
- 局外养成对基础攻击力的影响**每月上限为5%**，之后不再增长。意思是：你练一个月和练一年，基础数值差距不超过5%。
- 所有“修行残卷”的加成**仅在当前对局内生效**，战斗结束后清空。
- 新角色的解锁**不绑定付费**——所有角色均可通过游戏内货币（“炁晶”）抽取，炁晶可通过日常战斗获取。

**避免的负面约束**：
- ❌ 绝不设计“角色升星”系统——没有“抽到重复角色才能升星”的机制。
- ❌ 绝不设计“专属武器”绑定——任何角色都可以装备任何兵器/法器，只是适配度不同。
- ❌ 绝不用“体力系统”限制玩家——玩家可以无限次战斗，没有“体力耗尽”的挫败感。

### 3.3 角色多样性哲学：没有废物，只有不适合的环境

在《炁渊》中，**没有一个角色是“弱”的**，只有“在当前月令/炁候下不强势”的角色。

**设计约束**：
- 每个角色至少有一个**“绝对强势环境”**（某个月令+某个炁候+某套卡组的组合），在该环境下，该角色的胜率应显著高于平均。
- 每个角色至少有一个**“可玩环境”**（即使月令/炁候不利，仍可通过操作和构筑弥补）。
- 角色的强度差异**不超过15%**——即T0角色和T3角色在同一环境下的胜率差不超过15个百分点。

**避免的负面约束**：
- ❌ 绝不设计“版本弃子”——没有任何角色会被设计为“永远弱于其他角色”。
- ❌ 绝不设计“必须拥有的角色”——没有哪个角色是通关某关卡的唯一解。
- ❌ 绝不通过“削弱角色”来平衡——只通过“调整环境（月令/炁候）”来让不同角色轮流发光。


## 四、理念层面的设计哲学

### 4.1 文化理念：不是符号堆砌，是逻辑内化

《炁渊》使用道教文化、命理学、二十四节气，但**绝不做符号的简单堆砌**。

**什么是“符号堆砌”？**
- 角色名字叫“张三丰”，技能叫“太极拳”，但战斗逻辑和太极拳毫无关系。
- 界面画个八卦图，但八卦的卦象和玩法毫无关联。
- 节气只是背景板，换了个名字的“天气系统”。

**什么是“逻辑内化”？**
- **命理学**：十神不是标签，是行为逻辑。七杀命格的角色，其战斗方式就是“击杀后滚雪球”——这符合七杀“暴戾、制衡、以杀止杀”的命理含义。
- **二十四节气**：不是天气，是**规则改变器**。芒种“强制进攻”对应农忙时节的紧迫感；大雪“格挡自动弹反”对应冬藏时节的以守为攻。
- **道家哲学**：“性命双修”不是口号，是**数值铁律**。基础数值（命）永远优先于机制特效（性）。
- **道家典籍**：卡组不是“技能树”，是**哲学理念的玩法化演绎**。《道德经》卡组的“逆转机制”对应“反者道之动”，《南华经》卡组的“无视规则”对应“逍遥游”。

**设计约束**：
- 每一个文化元素的使用，都必须回答：“如果去掉这个文化外衣，这个机制是否依然成立且有趣？”如果答案是“是”，说明文化只是皮，需要重新设计。
- 所有文化元素的名称、效果、视觉表现，必须经得起**相关文化背景玩家的审视**。可以创新，但不能胡编。
- 每套典籍卡组的机制，必须能在原文中找到**至少三处理论依据**。

**避免的负面约束**：
- ❌ 绝不把文化元素当作**营销噱头**——不搞“国风联动”但玩法毫无关联的活动。
- ❌ 绝不**篡改文化核心含义**——例如，不会把“十神”中的“七杀”设计成治愈系技能。
- ❌ 绝不**堆砌文化符号**——不在一个界面上同时出现八卦、太极、星宿、符箓、节气、天干地支，导致视觉混乱。

### 4.2 玩家理念：尊重时间，尊重智力，尊重情绪

**尊重时间**：
- 一局战斗时长**控制在8~12分钟**。足够展开六层变量的策略博弈，但不至于让人疲劳。
- 所有动画可跳过，所有重复操作可一键完成（如“自动调息”按钮）。
- 没有“日常任务”强制打卡——玩家想玩就玩，不想玩不会有“落后焦虑”。

**尊重智力**：
- 不设计“无脑强”的卡牌——每张牌都有适用场景和代价。
- 不设计“隐藏数值”——所有伤害公式、触发概率、克制倍率，全部在游戏内可查。
- 不设计“付费即赢”——付费只买外观和新角色，不买胜率。

**尊重情绪**：
- 败北时，结算界面显示“本局最佳操作”而非“你的不足”——强调玩家做对了什么，而非做错了什么。
- 连胜时，不会强制匹配“更强对手”来打压——让玩家享受连胜的快感。
- 每个角色都有**败北专属台词**，且台词体现其性格，而非通用的“我输了”。

**设计约束**：
- 每局战斗的**决策点不少于15个**（出牌选择、调息时机、架势切换、弹反窗口、目标选择、卡组机制触发等），确保策略密度。
- 所有随机因素（偏财抽牌、炁候抽取）的**概率公开**，且在游戏内可查。
- 败北结算界面的**正面反馈与负面反馈比例不低于3:1**。

**避免的负面约束**：
- ❌ 绝不设计“付费才能继续”的卡点。
- ❌ 绝不设计“每日必做”的强迫性任务。
- ❌ 绝不用“损失厌恶”来驱动付费（如“限时礼包，错过再等一年”）。

### 4.3 平衡理念：动态平衡，而非静态平衡

《炁渊》的平衡不靠“削弱强势角色”，而靠**“环境轮转”**。

- 本月金旺，物理系强势？下个月水旺，法系崛起。
- 本局抽到“芒种”，快攻流起飞？下局抽到“大雪”，龟缩流翻身。
- 某个角色在当前月令下T0？下个月令它可能T3，但另一个角色会补上T0位置。

**设计约束**：
- 每月更新月令时，同步更新**环境报告**，告知玩家本月强势流派和角色，帮助玩家快速适应。
- 每个赛季（3个月）进行一次**大数据复盘**，如果某个角色连续3个月处于T0，则通过调整其“适配炁候”来间接降温，而非直接削弱数值。
- 所有平衡调整必须**提前2周公告**，并附带调整理由。

**避免的负面约束**：
- ❌ 绝不进行“暗改”——所有数值调整必须公开。
- ❌ 绝不因为“玩家抱怨”就削弱角色——只根据大数据和设计意图调整。
- ❌ 绝不追求“绝对平衡”——允许存在“当前环境下的强势角色”，这是策略游戏的乐趣之一。


## 五、文化深度约束——拒绝修仙文/修仙手游撞车

### 5.1 必须规避的修仙套路

| 大众修仙元素       | 《炁渊》的替代方案                       | 替代理由                                                     |
| ------------------ | ---------------------------------------- | ------------------------------------------------------------ |
| **灵根/天赋**      | **日主（本命五行）+ 十神命格**           | 灵根是“天生资质”的静态标签，十神是“行为逻辑”的动态法则。前者决定“你能不能练”，后者决定“你怎么打” |
| **筑基/金丹/元婴** | **无境界划分，只有“炁量上限”的成长**     | 境界划分本质是“数值门槛”的包装，与我们的“六层变量嵌套”策略理念冲突。我们不需要“等级墙” |
| **宗门/门派**      | **阵营（道门正宗/散修野士/自在天）**     | 宗门是“归属感”的组织，阵营是“理念认同”的立场。前者提供技能树，后者提供剧情选择 |
| **法宝/灵器**      | **兵刃+法器双槽**                        | 法宝是“越古越好”的等级装备，兵刃/法器是“搭配决定风格”的构筑组件。前者是数值堆砌，后者是策略选择 |
| **渡劫/飞升**      | **无飞升概念，只有“炁贯周天”的瞬时突破** | 渡劫是“一次性大事件”，炁贯周天是“每回合都可能触发的小突破”。前者是剧情高潮，后者是战斗节奏 |
| **丹药/灵石**      | **修行残卷（局内掉落，本局生效）**       | 丹药是“永久养成资源”，残卷是“局内临时强化”。前者是局外数值积累，后者是局内策略博弈 |
| **仙魔/正邪**      | **心猿（执念实体化）**                   | 仙魔是“阵营对立”的道德标签，心猿是“心理问题”的具象化。前者是脸谱化反派，后者是每个人都有的人性弱点 |

### 5.2 必须深挖的道家内核

| 道家内核       | 游戏化表达                               | 具体设计                                                     |
| -------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **炁**         | 双脉资源系统                             | 不是“灵力/法力”的泛化能量，而是分为任脉（阳炁）和督脉（阴炁）的双轨资源。阴阳可以互转，但转换有代价 |
| **周天**       | 炁贯周天机制                             | 不是“打坐回蓝”的被动回复，而是“阴阳两脉同时消耗达到阈值”的主动触发。强调“运转”而非“积攒” |
| **性命双修**   | 基础数值（命）优先于机制特效（性）的铁律 | 不是“双修=均衡发展”的泛化描述，而是“没有命，性无从发挥”的硬性约束。攻击力不达标，一切机制刮痧 |
| **五行**       | 相生相克+旺衰系统                        | 不是“属性克制”的简单循环，而是“旺相休囚死”的动态环境。同一个五行，在不同月令下的表现天差地别 |
| **十神**       | 角色行为逻辑法则                         | 不是“性格标签”的文案描述，而是“击杀减费”“锁血保命”“抽牌翻倍”等硬性规则。十神即被动，被动即命格 |
| **二十四节气** | 每局随机战场环境                         | 不是“天气系统”的视觉点缀，而是“改变规则”的环境变量。节气决定你这局“该怎么打”，而不是“打起来好不好看” |
| **月令**       | 每月更新的全局环境                       | 不是“赛季主题”的文案包装，而是“五行旺衰”的硬性规则。申月金旺，物理系崛起；亥月水旺，法系称王 |
| **天干地支**   | 角色命格标识（如“庚金·七杀”）            | 不是“生辰八字”的算命噱头，而是“角色定位”的精准描述。庚金代表刚锐，七杀代表暴戾，两者结合就是“越危险越强”的刀客 |
| **道藏典籍**   | 卡组核心                                 | 不是“技能树”的命名来源，而是“玩法机制”的哲学根基。每套卡组都是某部典籍的玩法化演绎 |

### 5.3 文案与UI的文化约束

**文案层面**：
- 所有技能名称、卡牌名称、装备名称，必须符合**道家典籍的用语习惯**，不得出现现代白话或修仙文常用词汇（如“傲天”“逆天”“绝世”“无敌”）。
- 角色台词必须体现其**日主+十神+卡组**的三重身份。例如：使用《道德经》卡组的庚金·七杀角色，其台词应同时体现“刚锐”“暴戾”“以柔克刚”三层气质。
- 剧情文本必须避免“修仙文套路”——不写“废柴逆袭”“退婚打脸”“宗门大比”，写“心猿讨伐”“执念化解”“道心抉择”。

**UI层面**：
- 所有图标、边框、纹样，必须取自**真实的道家文化元素**——符箓、卦象、星宿、云雷纹、饕餮纹、四神纹，不得使用“修仙手游常见的龙纹/凤纹/仙鹤/祥云”等泛化装饰。
- 五行属性标识必须使用**中国传统的五正色**，并配套独立的纹理标识（火行=火焰纹、水行=波浪纹、木行=藤蔓纹、金行=回纹、土行=龟裂纹）。
- 所有动画特效必须遵循**水墨+金箔**的视觉语言，不得使用“修仙手游常见的光污染/粒子爆炸/彩虹渐变”。


## 六、内部逻辑自洽与统一

### 6.1 底层逻辑框架

《炁渊》的所有系统，共享以下五条底层逻辑。任何新系统的设计，都必须与这五条逻辑兼容，不得出现断裂。

| 底层逻辑         | 核心表述                                                     | 在所有系统中的体现                                           |
| ---------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **阴阳互根**     | 一切资源、状态、效果都分为阴阳两面，且可以互相转化，但转化必有代价 | 炁分阴阳；十神分正偏；月令分旺衰；卡组分攻守                 |
| **性命双修**     | 基础数值（命）永远优先于机制特效（性）。没有命，性无从发挥   | 破防阈值；伤害公式；架势只提供倍率，不替代基础攻击           |
| **天时地利人和** | 天时（月令+炁候）≤30%，地利（装备+架势+卡组）≈40%，人和（十神+操作）≥30% | 月令/炁候不碾压；装备/架势/卡组决定战术；十神/操作决定上限   |
| **五行生克**     | 五行之间存在相生相克关系，且受月令旺衰影响而动态变化         | 术法属性克制；月令旺衰影响五行效果；卡组与五行的适配度       |
| **因果承负**     | 一切行为皆有后果，且后果延迟生效                             | 《太上感应篇》卡组的因果机制；炁候的“芒种强制进攻”带来的自损；十神七杀的击杀滚雪球 |

### 6.2 各系统之间的逻辑一致性校验

**校验一：炁候与卡组的逻辑一致性**
- 炁候改变“规则”，卡组提供“玩法”。两者必须逻辑兼容。
- 例如：“大雪”（格挡自动弹反）与《清静经》卡组（鼓励“无为”和“守一”）逻辑一致——都是“以静制动”的哲学。
- 例如：“芒种”（强制进攻）与《道德经》卡组（鼓励“无为”）逻辑**表面冲突**，但《道德经》的“反者道之动”恰恰可以在“被迫进攻”的情况下触发逆转——**冲突本身成为策略深度**。

**校验二：十神与卡组的逻辑一致性**
- 十神是“行为逻辑”，卡组是“哲学理念”。两者必须能够互相解释。
- 例如：七杀（击杀减费）与《阴符经》（盗机、预判）逻辑一致——都是“抓住时机，一击致命”的哲学。
- 例如：正印（锁血保命）与《度人经》（救赎、转化）逻辑一致——都是“守护与转化”的哲学。
- 若某角色的十神与卡组逻辑**表面冲突**（如正印配《阴符经》），则通过角色的**背景故事**来解释——正印的“守护”与《阴符经》的“盗机”结合，可以诠释为“守护重要之人而不择手段”的反英雄逻辑。

**校验三：月令与所有系统的逻辑一致性**
- 月令决定“五行旺衰”，所有系统都必须对月令做出合理响应。
- 炁候（节气）本身有五行属性，月令会影响炁候的效果强度。
- 十神（角色命格）有本命五行，月令决定其“得令”或“失令”。
- 卡组（典籍）有自己的五行倾向，月令决定其“顺势”或“逆势”。
- 装备（兵刃/法器）有五行属性，月令决定其“加成”或“减益”。
- **任何系统都不能对月令“无响应”**——若某系统对月令不敏感，则说明该系统与核心逻辑脱节，必须重新设计。

**校验四：所有系统的命名逻辑一致**
- 所有系统命名必须符合**道家典籍的用语习惯**，不得出现现代白话或修仙文常用词汇。
- 正确示例：“炁候”“月令”“十神”“日主”“道枢”“兵刃”“法器”
- 错误示例：“天气系统”“月份加成”“角色被动”“技能树”“武器”“装备”
- **一致性要求**：若“月令”使用地支命名（寅月/卯月），则“炁候”使用节气命名（立春/惊蛰），两者都是“天时”的不同层级，命名逻辑必须统一。

### 6.3 禁止事项清单（内部逻辑自洽）

| 禁止事项                 | 违反的底层逻辑                   | 替代方案                                             |
| ------------------------ | -------------------------------- | ---------------------------------------------------- |
| 设计“无视防御”的廉价手段 | 性命双修（命优先于性）           | 所有无视防御的效果必须附带极高代价（如消耗50层“势”） |
| 设计“纯机制流”角色       | 性命双修（性不能替代命）         | 所有角色的技能组都必须依赖基础攻击力                 |
| 设计“唯一解”卡组         | 天时地利人和（环境变量必须存在） | 每套卡组都有“强势环境”和“弱势环境”                   |
| 设计“静态强弱”的角色     | 五行生克（动态变化）             | 角色强度随月令/炁候动态变化                          |
| 设计“无代价”的阴阳转换   | 阴阳互根（转化必有代价）         | 所有阴阳炁转换都有比例损耗（2:1或1.5:1）             |
| 设计“无响应”的系统       | 所有系统必须对月令/炁候有响应    | 任何系统都必须至少受月令/炁候之一的直接影响          |
| 使用修仙文常用词汇命名   | 文化深度约束（拒绝撞车）         | 所有命名必须取自道家典籍原文                         |
| 设计“永久养成”的数值系统 | 天时地利人和（局内为主）         | 局外养成对数值影响≤5%，核心成长在局内                |

## 八、最终核心理念总结

> **《炁渊》是一款以中国传统色为视觉底色、以道教“炁”与命理学为策略骨架、以二十四节气为动态战场、以道家典籍为卡组灵魂的回合制卡牌游戏。**
>
> 它拒绝赛博朋克的泛用霓虹，回归敦煌与故宫的正统色谱；
> 它摒弃局外数值碾压，将所有策略深度压在**月令、炁候、十神、架势、装备、卡组**的六重嵌套里；
> 它让“挨打”变成“攒资源”，让“回合制”充满“弹反、连携、破绽”的即时微操；
> 它用“性命双修”的铁律守护数值公平，用“战斗爽”的视听轰炸兑现每回合的情绪价值；
> 它从《道德经》到《太上感应篇》，让每一套卡组都成为一部道家典籍的玩法化演绎；
> 它拒绝修仙文的套路，深挖道家文化的哲学内核，让每一个命名、每一帧动效、每一次触发都有典可循。
>
> **在这里，每一局都是天时、地利、人和的重新排列——你的道，由天定，也由你定。**
