# 炁渊 · QI ABYSS

新中式绮丽 · 回合制卡牌对战手游（手机竖屏 390×844）

> 以中国「五正色 + 干支历法」为骨、以「性命双修」为魂的卡牌对战。阳炁阴炁双资源、弹反微操、五行连携、二十四节气变量联动。

---

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 本地开发（浏览器打开后按 F12 → 设备工具栏 → 选手机尺寸）
npm run build      # 生产构建，产物在 dist/
npm run test       # 运行单元测试
npm run lint       # 静态检查
```

> 若 `npm run build` 报 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`，是沙箱对 `dist/art` 批量删除的保护，
> 用 `npm run build:safe` 绕过，或先手动删除 `dist` 目录。

## 技术栈

Vite 8 + React 19 + TypeScript 6 + oxlint + vitest

无第三方 UI 库、无状态管理库。配色统一由 CSS 变量管理（`src/styles/tokens.css` 是全项目唯一出现 hex 的文件）。

## 核心系统

| 系统 | 说明 |
|---|---|
| **双脉炁资源** | 阳炁（攻击/击杀获得）+ 阴炁（受击/格挡获得），可 2:1 互转 |
| **弹反微操** | 敌方前摇后进入判定窗，红区=普通格挡（减伤 60%），金区=完美弹反（免伤+追击） |
| **奥义卡** | 两张同属性牌合并，伤害 (A+B)×1.5，不消耗额外回合 |
| **破绽** | 回合结束按连击/相克给敌人标记，下回合首张攻击牌必暴击且转真实伤害 |
| **三大架势** | 体修（叠「势」层数）/ 法修（五行相生链）/ 散修（阴阳差值转化暴击） |
| **装备附魔** | 3 兵刃 + 3 法器，9 种组合产出不同斩击，双兵刃/双法器/一兵一法各有流派 |
| **五层变量联动** | 月令 → 炁候（节气）→ 十神 → 架势 → 装备 |
| **敌人招式牌组** | 每只心猿有独立招式牌组与「势」资源，出招有成本有品阶（常/技/凶/杀） |
| **阴阳双阵营** | 阴执（都市戾气：焦躁鬼/加班怨灵/贪嗔蠹）+ 阳华（节令精怪：金吾卫/春雷兽/冰魇） |

## 项目结构

```
src/
├── game/
│   ├── engine/          # 战斗引擎（确定性，无 Math.random / Date.now）
│   │   ├── battle.ts    # 回合状态机 + reducer
│   │   ├── damage.ts    # 7 段伤害结算管线（含虚弱/破甲）
│   │   ├── hooks.ts     # 节气效果挂载点
│   │   └── rng.ts       # mulberry32 种子随机
│   ├── data/            # 纯数据：角色 / 卡牌 / 敌人 / 世界设定
│   ├── constants.ts
│   └── types.ts
├── components/
│   ├── BattleScreen.tsx # 战斗界面 + 弹反面板
│   ├── Screens.tsx      # 主页 / 编队 / 结算 / 开场
│   ├── svg/Figure.tsx   # 立绘（AI 图优先，失败回退程序化 SVG）
│   ├── svg/Glyphs.tsx   # 五行纹样 / 八卦底盘 / 状态图标
│   └── ui/Primitives.tsx# 描金面板 / 玉牌按钮 / 流光炁条
└── styles/
    ├── tokens.css       # 颜色 / 字体 / 间距变量（唯一 hex 出处）
    └── global.css
```

## 设计约定

- **确定性引擎**：禁用 `Math.random` 与 `Date.now`，随机数走 `state.rngState`（mulberry32），
  弹反时间从 UI 以 `elapsedMs` 传入。相同种子必然产生相同战局。
- **「性命双修」用类型强制**：`DamageModifier` 的 `addBase` 算子只允许装备来源，其余来源运行时抛错。
  全乘法结构使五层变量的计算顺序与结果无关，消灭顺序依赖 bug。
- **节气零改引擎**：`engine/hooks.ts` 是全引擎唯一读 `solarTermId` 的地方，新增节气只加数据。
- **禁止无响应系统**：任何声明的状态都必须在引擎里有真实效果，且**敌我双向结算**
  （虚弱/破甲在 `damage.ts` 中实装，灼烧在每个回合对敌我双方都跳）。
- **美术资源兜底**：`public/art/` 下的 AI 生成图为真透明 PNG 抠图，
  加载失败时自动回退程序化 SVG 立绘，不会白屏。

## 语言与命名约定

本项目为中文项目，**非必要一律使用中文**：

- 全部说明文档使用简体中文
- 所有**用户可见文本**（角色名、卡牌名与描述、按钮、提示、战报日志）使用简体中文
- 代码注释使用简体中文
- `index.html` 采用 `lang="zh-CN"`

**文件命名强制中文**（本条为硬约束）：

- **素材库**（`public/` 全目录）：文件名一律中文，采用「语义前缀_中文名」格式，
  如 `bg_战场.png`、`char_陆青崖.png`、`enemy_金吾卫.png`、`站点图标.svg`
- **文档**（`docs/` 全目录）：文件名一律中文，如 `玩法介绍.md`、`设计哲学.md`、`类图.mermaid`
- 新增素材/文档时必须遵守；重命名后必须同步更新代码引用（`Figure.tsx` 的路径映射、
  背景 `url()`、`index.html` 的图标引用）与文档间的交叉链接

以下为**工程必要的英文例外**，不受上述约束：

- 代码标识符：变量名、类型名、枚举值、CSS 自定义属性名
- 行业通用缩写：`P0/P1/P2`、`T01–T05`
- 仓库根 `README.md`（GitHub/Gitee 首页约定的固定文件名，改名会导致首页不再渲染）
- `package.json`、`tsconfig.json`、`vite.config.ts` 等工具链配置文件名
- `src/` 下的源码文件名（属代码资产而非文档/素材，且与 import 路径强绑定）
